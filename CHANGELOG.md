# Changelog

## 1.0.0 (2026-10-11)


### ⚠ BREAKING CHANGES

* Thalos:Memory:RalphRecall is now Thalos:Memory:LearningsRecall, and a configuration that still sets the old key fails at startup.
* /api/ralph-config, /api/executionsessions and POST /api/tasks/{id}/abandon and /resume are removed, as is the RalphLoop configuration section.
* the daedalus-console image is no longer built or published.
* **tasks:** CreateTaskDto and UpdateTaskDto no longer accept completionPromise or maxIterations.
* **costs:** GET /api/cost-analytics/by-session and ICostAnalyticsService.GetCostsBySessionIdAsync are removed. In the summary response, TotalExecutions is renamed to TotalEntries, TotalTasks is removed, and TotalCacheReadTokens, TotalCacheWriteTokens, UnreadableRecords, BySource, ByModel and ByDay are added.
