# Phase 3.6 Native API, CLI and Migrations Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Api, Cli, Migrations and Sandbox publish with Native AOT in CI at zero trim and AOT warnings with no suppressions, the suites and a live run pass on the native Api, and start-up, working set and image size are measured.

**Architecture:** Clear the two warning sources at their roots (the outbox serializer in Daedalus, YamlDotNet's reflection path in the package that reaches it), flip `PublishAot` on in the csproj files and ratchet the baseline to 0. Native proof comes from a label-gated CI job that publishes a test host natively and runs Playwright.Api against it.

**Tech Stack:** .NET 10, Native AOT (ILC), ZeroAlloc.Outbox 4.x, System.Text.Json source generation, NUnit, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-11-phase-3.6-native-publish-design.md`

## Global Constraints

- No Native AOT publish on the agents VM. CI only: push the branch and read the `aot-analysis` and `Native publish` logs. The `native-publish` label on the phase PR produces binaries.
- No `UnconditionalSuppressMessage`, no `NoWarn` for IL codes, no rd.xml or trimmer roots, no raising a baseline.
- `dotnet build` and `dotnet test` one at a time with `DOTNET_USE_POLLING_FILE_WATCHER=1`. Do not reinstall Playwright browsers. The 3 `RunScopedRoslynRoutingTests` fail only on the agents VM.
- Versions only in `Directory.Packages.props`. `[LoggerMessage]` logging, primary constructors, `Result<T>` for expected failures.
- Never work on or push to main. Push with `git push origin phase/3.6-native-publish:phase/3.6-native-publish`.
- Commit bodies: lines at most 100 characters, no nested parentheses, no Co-Authored-By and no Claude signature or session link.
- The HTTP contract and what the suites assert stay unchanged.

## Review Focus

- An outbox row written by the 3.x reflection serializer must still deserialize through the dispatcher (existing rows in the table). Pinned in Task 2.
- A payload type missing from the new JSON context must fail loudly in a test, not at runtime in production. Pinned in Task 2.
- The native test host must not weaken what Playwright.Api asserts: same overrides as the in-memory fixture. Pinned in Task 5.
- A native-only runtime failure that JIT hides (missing metadata for a request body or config binding). Pinned in Task 6 by the native suites.
- `eng/aot/baseline.json` lowered by hand without a clean publish behind it. Pinned in Task 4 by the ratchet.
