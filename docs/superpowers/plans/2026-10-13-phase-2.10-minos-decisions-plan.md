# Phase 2.10 Per-node Model and Tool Selection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Before a manufacture node runs, Minos.NET decisions over OpenRouter choose its model and tool families from
the sets its role allows, only ever narrowing them, and fall back to today's behaviour whenever a decision cannot be
trusted.

**Architecture:** Part A, in Thalos.NET: `SubagentRunRequest` gains a model override and a tool filter, checked inside
the engine against the agent's own `AllowedModels` and resolved tools, and released as Thalos 0.17.0. Part B, in
Daedalus: a `NodeSelectionRunner` decorator asks one Minos question set per node dispatch, records the decision as a
run record, reuses it on redelivery, and sets the overrides. A review replay process and a live comparison decide
whether cheaper models become the default.

**Tech Stack:** .NET 10, C# 13, Thalos.NET 0.17.0, Minos.NET 1.0.1 (`Minos.NET.SystemOne`), ZeroAlloc.Results,
EF Core on PostgreSQL, xUnit, AwesomeAssertions, NSubstitute, Aspire.

**Spec:** `docs/superpowers/specs/2026-10-13-phase-2.10-minos-decisions-design.md`

## Global Constraints

- **Narrow, never widen:** a turn is offered at most the agent's resolved tools, and a model only from the agent's
  `AllowedModels` or its own default model. Enforced in Thalos, not only in Daedalus.
- **Fallback is today:** no OpenRouter key, a failed or slow decision, or a confidence below threshold means the
  configured default model and the full tool list.
- **Decide once per node visit,** outside `ReviewLensRunner`, so the three lens passes share one decision and one
  cached prefix. Reuse the recorded decision on redelivery.
- **After any rejected review,** tool narrowing is off for the rest of the run. Signal: `run.Visits["review"] > 1` or
  `run.Visits["implement"] > 1`.
- **Never removable, by family:** the node's outcome tool (engine-supplied, so it is never in the filter's scope),
  `daedalus` on every node (it holds `daedalus__report_review_outcome`), and `workspace` on every node.
- **Never decided by Minos:** review verdicts, the human gate, publish.
- **Task text** goes to OpenRouter only when `Thalos:Decisions:ZeroDataRetentionAccount` is `true`. Otherwise decisions
  stay off and start-up logs why.
- **Secrets:** the OpenRouter key comes from AppHost parameter `openrouter-key` as env `OPENROUTER_API_KEY`. It never
  reaches a log, span, run variable or record.
- **Telemetry** carries the node, role, chosen level, kept family count, confidence and fallback reason, never task
  text and never tool names.
- **Central package management:** versions only in `Directory.Packages.props`.
- **Commit messages:** conventional, body lines at or under 100 characters, no nested parentheses.
- **Falsifiability:** every assertion red-verified by the change that breaks it, noted in the test's summary as
  `Red:`.
- **Never commit** the local Minos package source in `nuget.config`, or anything under the local package folder.

## Review Focus

1. **Minos answers late.** A decision past `Thalos:Decisions:Timeout` must give the defaults, not stall the node. Test:
   Task B3, `A_decision_slower_than_the_timeout_keeps_the_defaults`.
2. **A role's configured model menu lists a model with no price.** Cost analytics would show zero cost for it. Test:
   Task B1, `Every_allowed_model_has_a_price`.
3. **A redelivered dispatch after the decision record was written.** It must not ask Minos again or pick differently.
   Test: Task B4, `A_redelivered_dispatch_reuses_the_recorded_decision`.
4. **The pinned charter revision changes the default model between visits.** The decision maps levels onto the
   allowed list, never onto a model outside it. Test: Task A2,
   `A_model_override_outside_the_allowed_list_is_refused`.
5. **A tool filter that names a family the agent does not hold.** Must be refused loudly, not silently offer nothing.
   Test: Task A2, `A_tool_filter_entry_matching_none_of_the_agents_tools_is_refused`.
