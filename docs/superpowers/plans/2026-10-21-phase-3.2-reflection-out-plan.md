# Phase 3.2 Our Own Reflection Out Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every reflection site in Daedalus' and Thalos' own code moves to a compile-time path with behaviour
unchanged on JIT; the native CLI reaches "Application started" and the native API gets past every blocker 3.2 owns.

**Architecture:**
- **AI.Sentinel 2.4.0** ships from a new `release/2.x` branch: the IL2069 fix and a name- or id-based detector disable.
- **Thalos 0.19.0** ships once, from one PR: JSON contexts, the JSON-shaped variable contract, DI annotations, the binder
  and YAML generators, typed tool sources with a public options factory, `IsAotCompatible` everywhere but Testing, and
  a native probe host.
- **Daedalus** does everything that needs no new Thalos API on 0.18.0 first (Tasks 12-19), then bumps to 0.19.0 alone
  and finishes the tool registration, the outbox reader and the detector disable (Tasks 20-23).
- Every swap is guarded by a golden captured from the reflective path **before** the swap.

**Tech Stack:** .NET 10 (SDK 10.0.402), System.Text.Json source generation, the configuration binder generator,
`Vecc.YamlDotNet.Analyzers.StaticGenerator`, ZeroAlloc.Mediator's generated `AddMediator`, Microsoft.Extensions.AI
`AIFunctionFactory`, NativeAOT, release-please.

**Spec:** `docs/superpowers/specs/2026-10-21-phase-3.2-reflection-out-design.md`, read with its "Corrections" section.
**Impact analysis:** `docs/superpowers/specs/2026-10-21-phase-3.2-reflection-out-impact-analysis.md`. Its "Affected
Files" table is the authoritative file list and gives each JSON site's current options; its risk numbers (R1-R19)
are cited below.

## Global Constraints

- **No suppressions for trim or AOT warnings.** No `UnconditionalSuppressMessage`, and no `<NoWarn>` for IL2xxx or
  IL3xxx. A `[Requires*]` attribute moved to another member is not a fix. `#pragma warning disable IL20xx` goes too.
- **Each suppression comes out in the same commit as its fix.** Only Api's assembly-level IL2026 is a bare removal,
  re-baselined upward with that cause.
- **The two-way ratchet:** `eng/aot/count-warnings.sh --check` fails on any count above **or** below
  `eng/aot/baseline.json`. Every count change runs `eng/aot/count-warnings.sh --target <X> --write` and commits the
  baseline in the same commit, with the cause in the message.
- **SDK:** `global.json` pins `10.0.402` with `rollForward: disable`. Thalos and AI.Sentinel keep their own
  `global.json`.
- **Central package management:** `Directory.Packages.props` owns every version; `PackageReference` has no `Version`.
  This holds in Daedalus and Thalos. AI.Sentinel 2.x has no CPM and keeps its own form.
- **Commits:** body and footer lines at most 100 characters; no nested parentheses anywhere in a message; a blank line,
  then `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`; no session URLs; `dotnet format` before committing.
  Thalos and AI.Sentinel commits are conventional and release-please must be able to parse every one.
- **Every new assertion carries a `Red:` line** naming the code change that turns it red, applied once and seen failing.
- **Integration tests** run with `DOTNET_USE_POLLING_FILE_WATCHER=1`.
- **Secrets:** read the Keycloak `dev` password, the client secret and the Anthropic key at run time; never print them.
- **ZeroAlloc.ORM:** no issues are filed.
- **The Anthropic issue** is filed only after checking the latest SDK release and reproducing the failure in a native
  run, not from warnings alone.
- **The owner merges every PR** and every release-please PR. A task that opens a PR stops there.
- **Byte identity** is tested at the serializer output, never on a `jsonb` row; stored rows get read tests over
  existing JSON; the outbox payload is tested byte for byte on both sides.
- **Reflection stays allowed in tests**: the reflective paths survive in test code as oracles.
- **Out of 3.2:** `ZeroAlloc.Inject`, `ZeroAlloc.Resilience`, `ValueObjects.EfCore`, `Outbox.EfCore`, MVC anonymous
  error bodies (3.4), Web JSInterop (3.7), SignalR's fallback, `ScriptedChatClient`, AI.Sentinel 3.x.

## Review Focus

1. **Model output read leniently:** `"line":"12"`, `"Severity":"high"`, and an enum sent as `2` must still parse, as
   today. Pinned in Task 16 (`ReviewEvidence`, `ApprovingReview`) and Task 17 (`BrainstormService`).
2. **Open `object` values written into rows:** every value shape a node can report (string, long, double, bool,
   null, string list, nested map) writes the same bytes, and a non-JSON type fails naming its type, on JIT as well as
   native. Pinned in Task 16 (`ReviewResponseRecord`) and Task 5 (Thalos variables).
3. **Tool result bytes:** a result holding `<`, `&`, `'`, `é` and an emoji serialises with the same encoder on the
   typed path as on the reflective one. Pinned in Task 8, Task 18 and Task 21.
4. **Variable read-side types:** after start, node result and resume, `WorkflowRun.Variables` still holds `string`,
   `long`, `double`, `bool`, `Dictionary<string, object?>` and `List<object?>`, never `JsonElement`, so Daedalus'
   `as string` reads keep working, and the prompt block renders a string raw. Pinned in Task 5.
5. **YAML `int?` and dictionaries:** an absent `max_visits` or `quorum` stays null, a present one binds, and a
   `branch` map keeps its key order. Pinned in Task 7.

## Calls this plan makes

Not in the spec; each is cheap to reverse before its task runs.

- **Typed source access is a public factory, `LocalToolSources.Create<TTools>`,** not `InternalsVisibleTo`, so
  Memory, Skills and Sandbox do not depend on another package's internals. Its name keeps `LayeringTests` unchanged.
- **`GitActionTools` gets `AddGitActionTools(string)` in Thalos.NET.Git** (Task 8). Daedalus registers that Thalos
  class by `typeof` today, and the impact analysis' Thalos list had no typed path for it.
- **AI.Sentinel gets `TryDisableDetector` beside `DisableDetector`,** so Daedalus keeps its own startup message
  without catching an exception.
- **Daedalus writes its own `PlainJson` converter on 0.18.0** (Task 16), replaced by Thalos' `WorkflowVariableJson`
  at the bump (Task 20).
