## What this phase produced

- **Upstream.** Flux.Blazor references `Microsoft.AspNetCore.Components` instead of the ASP.NET Core shared framework,
  which has no browser-wasm runtime pack (NETSDK1082), with a Blazor WebAssembly smoke sample in CI. Thalos adds
  `IWorkflowRunQuery` (newest-first keyset listing, migration 1011) and `IWorkflowRunObserver` (called after commit, on
  the success path only, after the store released its connection).
- **API.** Run DTOs moved to `Daedalus.Application/DTOs/WorkflowRuns`, Thalos-free (`NodePinView`). The run view gains
  `Steps` and `Checked`. `GET /api/workflow-runs` lists runs with their board task. `/hubs/workflow-runs` broadcasts a
  content-free `WorkflowRunChanged` through a bounded channel. The access token is read from the query only under `/hubs`,
  redacted from server spans, and the hosting diagnostics log is held at Warning in code. The global rate limiter runs
  after authentication and keys on the caller's subject.
- **Web.** ZeroAlloc.Flux state for runs and tasks, effects as services, a hub connection that re-fetches on change and
  on reconnect, `/runs`, `/runs/{id}` with the approval gate, and `/tasks` on Flux.

## Incidents

- **Memory.** A full regression was stopped by the harness at 3.6 GB free of 64. Stopping a task stopped only its shell
  wrapper; the `dotnet test`/testhost tree kept running and was killed by PID. Two killed runs leaked 14 sandbox
  containers; they and two weeks of orphaned Aspire containers were removed with the owner's approval (volumes kept).
  Lesson: stop a test run's whole process tree.
- **Formatting.** `dotnet format --include` per file loads the solution once per file; one invocation with all files
  takes seconds.

## Red-verification notes

Every task report listed its Reds; every review checked them. Reds that did not fire as written, and what replaced them:
- A0.1's CI step rebuilt the libraries without `-p:Version`, so `Pack --no-build` packed 1.0.0.0 (ZAVERSION002); fixed
  in the PR (`ci:` commit).
- B4's codec: `Base64Url.TryDecodeFromChars` throws on invalid characters; `IsValid` first. Status parsing accepted numbers
  and comma lists (`Awaiting,Succeeded` filtered on Failed); name-only match.
- B5: OpenTelemetry.Instrumentation.AspNetCore 1.17 already redacts `url.query`; the processor's Red needed the opt-out
  flag on the test host. A plain `AddFilter` is overridden by provider configuration; `HostingDiagnosticsLogFilter`
  post-configures every rule that could match.
- Final review: the rate-limit partition test passed only because the test auth handler adds `ClaimTypes.Name`, which a
  Keycloak token does not carry; keyed on the subject and tested with a Keycloak-shaped principal and a real token.
- The scrollbar-gutter Red only fails in a browser that shows scrollbars; the layout test starts its own.
