# Phase 1.7 — Daedalus ZeroAlloc Migration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove `CSharpFunctionalExtensions` and both `FluentValidation` packages from Daedalus and replace the hand-rolled CQRS layer with `ZeroAlloc.Mediator`, so the packages are gone from the solution rather than merely unused.

### Task 4: Replace the action filter, preserving HTTP 400

**Files:**
- Create: `src/Daedalus.Api/Middleware/ValidationAdapter.cs`
- Create: `src/Daedalus.Api/Middleware/ZeroAllocValidationFilter.cs`
- Delete: `src/Daedalus.Api/Middleware/FluentValidationFilter.cs`

**Interfaces:**
- Consumes: the `[Validate]` DTOs from Task 3
- Produces: `IValidationAdapter` and `ZeroAllocValidationFilter`, registered by Task 5

**The design problem:** `ValidatorFor<T>` is abstract and exposes **no non-generic base type or interface** — verified by reflection. The current filter iterates untyped `ActionArguments` and resolves `IValidator<>` by `MakeGenericType`. That pattern cannot call `ValidatorFor<T>.Validate` without `MethodInfo.Invoke`, which would keep runtime reflection and defeat the point of adopting the library.

**The solution:** a tiny non-generic adapter, closed over each DTO type explicitly at registration. No reflection, AOT-clean, and the filter stays generic over the adapters.

- [ ] **Step 1: Write the adapter**

```csharp
using ZeroAlloc.Validation;

namespace Daedalus.Api.Middleware;

/// <summary>Non-generic seam over the generated <see cref="ValidatorFor{T}"/>.</summary>
public interface IValidationAdapter
{
    Type TargetType { get; }
    ValidationResult Validate(object instance);
}

public sealed class ValidationAdapter<T>(ValidatorFor<T> validator) : IValidationAdapter
{
    public Type TargetType => typeof(T);

    public ValidationResult Validate(object instance) => validator.Validate((T)instance);
}
```

- [ ] **Step 2: Write the filter, emitting exactly today's response**

```csharp
using Microsoft.AspNetCore.Mvc;
using Microsoft.AspNetCore.Mvc.Filters;

namespace Daedalus.Api.Middleware;

/// <summary>
///     Runs source-generated validators on action parameters before the action executes.
///     Returns a 400 Bad Request with RFC 7807 ProblemDetails on validation failure,
///     byte-identical to the response the FluentValidation filter produced.
/// </summary>
public sealed class ZeroAllocValidationFilter : IAsyncActionFilter
{
    private readonly Dictionary<Type, IValidationAdapter> _adapters;

    public ZeroAllocValidationFilter(IEnumerable<IValidationAdapter> adapters)
        => _adapters = adapters.ToDictionary(a => a.TargetType);

    public async Task OnActionExecutionAsync(ActionExecutingContext context, ActionExecutionDelegate next)
    {
        foreach (var argument in context.ActionArguments.Values)
        {
            if (argument is null || !_adapters.TryGetValue(argument.GetType(), out var adapter))
            {
                continue;
            }

            var validationResult = adapter.Validate(argument);
            if (validationResult.IsValid)
            {
                continue;
            }

            var errors = new Dictionary<string, string[]>(StringComparer.Ordinal);
            foreach (ref readonly var failure in validationResult.Failures)
            {
                errors[failure.PropertyName] = errors.TryGetValue(failure.PropertyName, out var existing)
                    ? [.. existing, failure.ErrorMessage]
                    : [failure.ErrorMessage];
            }

            var problemDetails = new ValidationProblemDetails(errors)
            {
                Status = StatusCodes.Status400BadRequest,
                Title = "One or more validation errors occurred.",
                Type = "https://tools.ietf.org/html/rfc7231#section-6.5.1"
            };

            context.Result = new BadRequestObjectResult(problemDetails);
            return;
        }

        await next();
    }
}
```

Note the grouping must preserve **insertion order per property**, matching the old `GroupBy` + `Select` behaviour.

Reproduce the CSFE contract captured by reflection — `IComparable`, `IComparable<Entity<TId>>`, `TId : IComparable<TId>`, and a **protected** `Id` setter that EF Core materialisation depends on.

```csharp
namespace Daedalus.Domain.Entities;

/// <summary>
///     Identity-based equality for domain entities. Replaces
///     CSharpFunctionalExtensions.Entity&lt;TId&gt;; behaviour is pinned by
///     EntityEqualityCharacterisationTests.
/// </summary>
public abstract class Entity<TId> : IComparable, IComparable<Entity<TId>>
    where TId : IComparable<TId>
{
    public TId Id { get; protected set; } = default!;

    public override bool Equals(object? obj)
    {
        if (obj is not Entity<TId> other)
        {
            return false;
        }

        if (ReferenceEquals(this, other))
        {
            return true;
        }

        if (GetUnproxiedType(this) != GetUnproxiedType(other))
        {
            return false;
        }

        // Transient entities are never equal, not even to themselves by value.
        if (EqualityComparer<TId>.Default.Equals(Id, default!))
        {
            return false;
        }

        return EqualityComparer<TId>.Default.Equals(Id, other.Id);
    }

    public override int GetHashCode() => (GetUnproxiedType(this).ToString() + Id).GetHashCode(StringComparison.Ordinal);

    public int CompareTo(Entity<TId>? other)
        => other is null ? 1 : Id.CompareTo(other.Id);

    public int CompareTo(object? obj) => CompareTo(obj as Entity<TId>);

    public static bool operator ==(Entity<TId>? a, Entity<TId>? b)
        => a is null && b is null || a is not null && b is not null && a.Equals(b);

    public static bool operator !=(Entity<TId>? a, Entity<TId>? b) => !(a == b);
    public static bool operator <(Entity<TId>? a, Entity<TId>? b) => a is null ? b is not null : a.CompareTo(b) < 0;
    public static bool operator >(Entity<TId>? a, Entity<TId>? b) => a is not null && a.CompareTo(b) > 0;
    public static bool operator <=(Entity<TId>? a, Entity<TId>? b) => !(a > b);
    public static bool operator >=(Entity<TId>? a, Entity<TId>? b) => !(a < b);

    /// <summary>Unwraps an EF Core lazy-loading proxy to its real entity type.</summary>
    private static Type GetUnproxiedType(object obj)
    {
        var type = obj.GetType();
        var name = type.ToString();
        return name.Contains("Castle.Proxies.", StringComparison.Ordinal)
            || name.EndsWith("Proxy", StringComparison.Ordinal)
                ? type.BaseType ?? type
                : type;
    }
}
```
