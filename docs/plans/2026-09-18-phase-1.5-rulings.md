### 9. Ruling pB6-A

Cost if wrong: a scoped store resolved outside a scope throws at resolution, loudly, at startup or on the first tick rather than silently. ### 24. Ruling 13-C

### 29. Ruling 15-A

plan defect six. StepDispatchers.cs:10 documents "No dispatcher in this file throws: every failure path ends in FailAsync" and the file contains no exception handling at all — a guarantee asserted in prose and absent in code. ### 33. Ruling 16-B

DROP ZeroAlloc.Scheduling from this phase. The sweeper becomes a plain BackgroundService on a one-minute PeriodicTimer. Fourth, the plan's job was already "thin on purpose" with all work in ScheduledRunStore, so only the trigger mechanism changes — the body is untouched, and the schedules' own cron expressions are parsed by our reconciler with Cronos either way. This changes what the roadmap says phase 1.5 delivers, which is why it is written up prominently rather than buried. It is reversible: the package slots back in later with the migration work if the human partner wants it. Cost if wrong: roughly forty lines of BackgroundService to delete, and the roadmap line to restore.
