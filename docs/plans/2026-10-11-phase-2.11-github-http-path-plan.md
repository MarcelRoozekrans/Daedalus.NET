# Phase 2.11: The GitHub HTTP Path, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every call Daedalus sends to GitHub and Azure DevOps goes through a generated, AOT-safe ZeroAlloc.Rest client
with typed errors. A write is sent exactly once, a repeated read costs no GitHub quota when nothing changed, and the
remaining rate limit is a gauge in the dashboard.

**Architecture:** One repository changes, in one PR on the existing branch.

- **The transport.** An internal `[ZeroAllocRestClient]` interface, `IGitHubRestApi`, has one method per endpoint
  `GitHubApi` calls today, with a source-generated `GitHubJsonContext` over all-nullable DTOs and a
  `GitHubErrorMapper` that turns every ZeroAlloc.Rest failure into a `GitHubError`. An error body is read up to 2 KiB
  only to summarise GitHub's own words for the agent (`GitHubSaid`) and to spot a secondary rate limit; the error's
  `Message` never carries it.
- **The facade.** `GitHubApi` stays the one class that knows GitHub's HTTP surface. It builds two generated clients over
  two named `HttpClient`s, `GitHub.Read` and `GitHub.Write`, and keeps everything that is not HTTP: the activity
  aggregation, paging, the 404-to-null rule of `GetIssueAsync` and the shape checks. `IGitHubReader` and `IGitHubWriter`
  return `Result<T, GitHubError>`.
- **The pipelines.** Reads, outside in: `GitHubConditionalCacheHandler`, the standard resilience handler with retries
  for everything transient except a `429`, `GitHubRateLimitObserver`. Writes: the standard resilience handler with a retry that never handles, then the
  observer. Azure DevOps gets its own generated client, a per-call `Authorization` header and the same never-retry rule.
- **The consumers.** The agent tools print `GitHubError.ForAgent()`, the message plus what GitHub said; `file-findings` says when a rate-limited node can be
  retried; the pull-request publisher shows the platform's body-free failure text on the run.

**Tech Stack:** .NET 10 / C# 13. ZeroAlloc.Rest 3.3.2 and ZeroAlloc.Rest.SystemTextJson 3.3.2 (generator bundled in
ZeroAlloc.Rest), ZeroAlloc.Results 1.4.0, System.Text.Json source generation, Microsoft.Extensions.Http.Resilience
10.3.0 (Polly v8), `System.Diagnostics.Metrics` `Gauge<long>`, OpenTelemetry 1.17 through phase 2.9's service
defaults. xUnit, AwesomeAssertions, NSubstitute, `Microsoft.Extensions.TimeProvider.Testing` (namespace
`Microsoft.Extensions.Time.Testing`), Testcontainers for the Integration suite.

**Spec:** `docs/superpowers/specs/2026-10-11-phase-2.11-scout-http-path-design.md`, decisions D1 to D6 and amendments
A1 and A2. It is binding. Where the code or a package disagrees with it, the findings F1 to F12 below give the evidence
and the rulings P1 to P31 decide. The pre-flight scan's findings K1 to K15, N1 to N4 and R1 to R2 are applied
(P31). Each deviation from the spec's wording is listed under "Deviations from the spec". Read the spec, the findings
and the rulings before any task.

## Global Constraints

- **Repository and branch.** `C:\Projects\Prive\daedalus`, branch `feat/phase-2.11-scout-http-path`, which carries the
  spec and this plan. `Daedalus.sln`. The whole phase is one PR. Do not push or open the PR without the owner.
- **Packages.** `ZeroAlloc.Rest` 3.3.2 and `ZeroAlloc.Rest.SystemTextJson` 3.3.2. `ZeroAlloc.Results` 1.2.4 → 1.4.0 and
  `ZeroAlloc.Collections` 1.2.0, floors set by ZeroAlloc.Rest 3.3.2. Each raised or new pin carries a comment naming the
  package that set its floor. No `ZeroAlloc.Rest.Generator`, no `ZeroAlloc.Rest.DependencyInjection`, no
  `ZeroAlloc.Cache`, no raw `Polly` package.
- **Central package management.** A `PackageReference` carries **no `Version` attribute**. Versions live only in
  `Directory.Packages.props`.
- **No response bodies in messages, run errors, logs or telemetry.** A `GitHubError.Message`, its `ToString()`, an Azure
  DevOps failure text, a run error, a log line and a span never copy a response body or an exception's message.
  GitHub's own words travel only in `GitHubError.GitHubSaid`, read from at most 2 KiB of error body
  (`MaxErrorBodyBytes = 2048` on `IGitHubRestApi`), and only the three agent tools render it, through
  `GitHubError.ForAgent()`. The Azure DevOps client reads no body (`MaxErrorBodyBytes = 0`) and logs none.
- **Build before testing.** Build each task's production project, for example
  `dotnet build src/Daedalus.Infrastructure`, before its tests: the repository treats analyzer warnings, Sonar and
  Meziantou included, as errors.
- **Writes are sent once.** POST, PATCH, PUT and DELETE to GitHub and Azure DevOps go out exactly once. Never add a retry
  to a write path, and never use `DisableForUnsafeHttpMethods` or `GetRequestMessage` (F1).
- **The gauge.** `daedalus.github.ratelimit.remaining`, unit `{request}`, on the meter `daedalus.github`, with one tag,
  `daedalus.github.resource`.
- **The cache.** In memory, process-wide, `200` entries of at most 256 KiB each, least recently used evicted, `GET`
  only, keyed on the method and the full URL.
- **Reads do not retry a `429`** (spec amendment A1). It is sent once and returns `RateLimited` with its retry time.
- **No workarounds.** No `#pragma`, `[SuppressMessage]`, `<NoWarn>` or `.editorconfig` severity change. The two existing
  `#pragma warning disable IL2026` lines in `GitHubApi.cs` and `AzureDevOpsPullRequestFactory.cs` are deleted, not
  moved. If a ZeroAlloc.Rest diagnostic (ZRA001 to ZRA006) or an analyzer fires on generated code, fix the declaration;
  if the generator itself is wrong, stop and report it with the diagnostic and the file under `obj/`.
- **CLAUDE.md conventions.**
  - Write `Result<T, E>.Success(..)` and `Result<T, E>.Failure(..)` explicitly. With `T` = `string` never return a bare
    value, because both `T` and `E` convert implicitly.
  - Primary constructors for DI, never mixed with a second constructor in one class. `GitHubApi` keeps its one
    traditional constructor.
  - `[LoggerMessage]` for every new log line.
  - No `.Result`, `.Wait()`, `.GetAwaiter().GetResult()`, `async void` or `Task.Run` to fake async.
- **Every assertion is falsifiable.** Each test's doc comment has one `Red:` line per assertion, naming the production
  change that turns it red. Make each change once, watch that assertion fail, then revert it. Report every `Red:` line
  that did not go red, and do not keep it.
- **Line numbers are hints.** Locate every edit by the quoted code. Earlier tasks shift later line numbers.
- **Files are CRLF.** Edit with the Edit tool. Never `sed -i` a tracked file: it rewrites line endings.
- **One `dotnet test` process at a time.** Never run two test commands in parallel; they share `obj/` and Docker.
- **Formatting.** Never run a bare `dotnet format`. Before each commit, run
  `dotnet format Daedalus.sln --verify-no-changes --include <file>` once per touched `.cs` file. If it reports a change,
  run it without `--verify-no-changes` for that file and re-run the tests.
- **Commit messages.**
  - Conventional: `feat`, `fix`, `refactor`, `test`, `docs`, `build`, `ci`, with a header of at most 100 characters.
    `fix:` only for a defect that shipped before this branch; a correction to this branch's own work is `refactor:`,
    `test:` or `docs:`.
  - Every body and footer line is at most 100 characters.
  - **No nested parentheses** anywhere in a body: release-please silently drops the commit. Write `typeof IFoo`.
  - The last line is `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never a `Claude-Session:` line or a
    `claude.ai` URL.
  - Commit with `git commit -m "<header>" -m "<body>" -m "Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>"`.
- **Docker.** `Daedalus.Tests.Integration` needs Docker with Linux containers. A suite that could not run is reported as
  not run, never as passing.
- **Owner gates.** Pushing, opening or merging the PR and running the live proof are stop-and-ask points, marked
  **OWNER-GATED**.

```csharp
using System.Net;

namespace Daedalus.Tests.Unit.Agents.GitHub;

/// <summary>
///     Records every outgoing request and replies from a queue keyed by path fragment, so a test can assert on what
///     was actually sent rather than only on what it chose to return.
/// </summary>
/// <remarks>
///     Each body is read when the request is sent. A ZeroAlloc.Rest client disposes the request, and its content, as soon
///     as the call returns, so a body read after the call would throw <see cref="ObjectDisposedException"/>.
/// </remarks>
internal sealed class StubHandler : HttpMessageHandler
{
    private readonly List<HttpRequestMessage> _requests = [];
    private readonly List<string?> _bodies = [];
    private readonly Dictionary<string, Func<HttpResponseMessage>> _routes = new(StringComparer.OrdinalIgnoreCase);

    public IReadOnlyList<HttpRequestMessage> Requests => _requests;

    /// <summary>The body of each request in <see cref="Requests"/>, or <see langword="null"/> for one without content.</summary>
    public IReadOnlyList<string?> Bodies => _bodies;

    public StubHandler Route(string containing, HttpStatusCode status, string json)
    {
        _routes[containing] = () => new HttpResponseMessage(status)
        {
            Content = new StringContent(json, System.Text.Encoding.UTF8, "application/json"),
        };
        return this;
    }

    public StubHandler Route(string containing, Func<HttpResponseMessage> respond)
    {
        _routes[containing] = respond;
        return this;
    }

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken ct)
    {
        _requests.Add(request);
        _bodies.Add(request.Content is null ? null : await request.Content.ReadAsStringAsync(ct).ConfigureAwait(false));

        foreach (var (fragment, respond) in _routes)
        {
            if (request.RequestUri!.PathAndQuery.Contains(fragment, StringComparison.OrdinalIgnoreCase))
                return respond();
        }

        return new HttpResponseMessage(HttpStatusCode.NotFound)
        {
            Content = new StringContent("""{"message":"Not Found"}""", System.Text.Encoding.UTF8, "application/json"),
        };
    }
}
```

```csharp
    /// <summary>A request's query as name to unescaped value, so a test compares parameters rather than their order.</summary>
    public static IReadOnlyDictionary<string, string> QueryOf(HttpRequestMessage request) =>
        request.RequestUri!.Query.TrimStart('?')
            .Split('&', StringSplitOptions.RemoveEmptyEntries)
            .Select(pair => pair.Split('=', 2))
            .ToDictionary(
                pair => Uri.UnescapeDataString(pair[0]),
                pair => pair.Length > 1 ? Uri.UnescapeDataString(pair[1]) : "",
                StringComparer.Ordinal);

    /// <summary>The query as <c>name=value</c> pairs sorted by name and unescaped, or empty when there is none.</summary>
    public static string CanonicalQuery(HttpRequestMessage request) =>
        string.Join('&', QueryOf(request).OrderBy(pair => pair.Key, StringComparer.Ordinal).Select(pair => $"{pair.Key}={pair.Value}"));

    /// <summary>Compares JSON by value, so a serializer's property order and escaping do not matter.</summary>
    public static void ShouldBeJson(string? actual, string expected) =>
        JsonNode.DeepEquals(JsonNode.Parse(actual ?? "null"), JsonNode.Parse(expected))
            .Should().BeTrue($"the body sent was {actual ?? "<none>"}");
```

```csharp
/// <summary>What kind of failure a GitHub call ended in. A consumer branches on this, never on the message.</summary>
public enum GitHubErrorKind
{
    /// <summary>GitHub refused for a rate limit: a 429, a 403 with <c>X-RateLimit-Remaining: 0</c>, or a 403 with <c>Retry-After</c>.</summary>
    RateLimited,

    /// <summary>404 or 410: the resource does not exist, or the token cannot see it.</summary>
    NotFound,

    /// <summary>401, or no token is configured.</summary>
    Unauthorized,

    /// <summary>A 403 that is not a rate limit.</summary>
    Forbidden,

    /// <summary>A 400, 422 or other 4xx, or a request Daedalus refused before sending it.</summary>
    Validation,

    /// <summary>409.</summary>
    Conflict,

    /// <summary>5xx.</summary>
    Server,

    /// <summary>The request failed before GitHub answered, or the resilience pipeline refused to send it.</summary>
    Transport,

    /// <summary>The request timed out, or GitHub answered 408.</summary>
    Timeout,

    /// <summary>GitHub's answer could not be read, or lacked a field Daedalus needs.</summary>
    Unreadable,
}

/// <summary>
///     A failed GitHub call. <see cref="Message"/> is built from the kind, the status and the retry time, or, for a refusal
///     Daedalus makes before sending, is Daedalus's own text. It never copies a response body or an exception's message:
///     GitHub's error text can quote what the request carried, and this message reaches agents, run errors and logs.
/// </summary>
/// <param name="Kind">What went wrong; the value to branch on.</param>
/// <param name="StatusCode">GitHub's status, or <see langword="null"/> when GitHub did not answer.</param>
/// <param name="RetryAt">When a rate limit lifts; set only for <see cref="GitHubErrorKind.RateLimited"/>.</param>
/// <param name="Message">One sentence for a person or an agent.</param>
public readonly record struct GitHubError(GitHubErrorKind Kind, int? StatusCode, DateTimeOffset? RetryAt, string Message)
{
    /// <summary>A refusal GitHub answered with <paramref name="status"/>. Only a rate limit keeps <paramref name="retryAt"/>.</summary>
    public static GitHubError FromStatus(int status, GitHubErrorKind kind, DateTimeOffset? retryAt)
    {
        var kept = kind == GitHubErrorKind.RateLimited ? retryAt : null;
        return new GitHubError(kind, status, kept, Describe(kind, status, kept));
    }

    /// <summary>A request Daedalus refused before sending it; <paramref name="message"/> is Daedalus's own text.</summary>
    public static GitHubError Refused(string message) => new(GitHubErrorKind.Validation, null, null, message);

    /// <summary>No token is configured; <paramref name="message"/> is the token source's text.</summary>
    public static GitHubError NoToken(string message) => new(GitHubErrorKind.Unauthorized, null, null, message);

    /// <summary>An answer of the wrong shape; <paramref name="message"/> is Daedalus's own text, never the answer.</summary>
    public static GitHubError Unreadable(string message, int? status = null) => new(GitHubErrorKind.Unreadable, status, null, message);

    /// <summary>The request timed out, on the client or in the resilience pipeline.</summary>
    public static GitHubError TimedOut() => new(GitHubErrorKind.Timeout, null, null, "The request to GitHub timed out.");

    /// <summary>The request failed before GitHub answered, or was not sent at all.</summary>
    public static GitHubError NotSent() => new(GitHubErrorKind.Transport, null, null, "The request to GitHub failed before GitHub answered.");

    /// <summary>The sentence <see cref="ForWrite"/> adds to a write that may have landed.</summary>
    public const string MayHaveLanded = "It may still have been applied: check before sending it again.";

    /// <summary>
    ///     GitHub's own words, summarised to one line of at most 300 characters, or <see langword="null"/>. For the agent
    ///     tools only, through <see cref="ForAgent"/>: it is never part of <see cref="Message"/> or <see cref="ToString"/>,
    ///     which reach run errors, logs and span status (spec amendment A2).
    /// </summary>
    public string? GitHubSaid { get; init; }

    /// <summary>The text an agent tool shows: the message, and what GitHub said when it said something.</summary>
    public string ForAgent() => GitHubSaid is { } said ? $"{Message} GitHub said: {said}" : Message;

    /// <summary>
    ///     The error of a write: a timeout, a server error or a transport failure may have happened after GitHub applied the
    ///     write, so the message says to check before sending it again. GitHub has no idempotency keys.
    /// </summary>
    public GitHubError ForWrite() =>
        Kind is GitHubErrorKind.Timeout or GitHubErrorKind.Server or GitHubErrorKind.Transport

            : this;

    public override string ToString() => Message ?? string.Empty;

        GitHubErrorKind.Unauthorized => $"GitHub answered {status}: the configured token was not accepted.",

        GitHubErrorKind.Timeout => $"GitHub answered {status}: the request timed out.",
```

```csharp
using System.Globalization;
using System.Text;
using System.Text.Json;
using ZeroAlloc.Rest;

namespace Daedalus.Infrastructure.Services.GitHub;

/// <summary>
///     Turns every ZeroAlloc.Rest failure of the generated GitHub client, <c>IGitHubRestApi</c>, into a
///     <see cref="GitHubError"/>. It is total: every <see cref="HttpErrorKind"/> maps. The kind, the status and the retry
///     time build the message; the error body, read up to 2 KiB, is used only for <see cref="GitHubError.GitHubSaid"/>
///     and to recognise a secondary rate limit (ruling P9). <see cref="HttpError.Message"/>, an exception's text, is
///     never read.
/// </summary>
/// <param name="clock">The clock a <c>Retry-After</c> delay, or a secondary limit's minute, is added to.</param>
internal sealed class GitHubErrorMapper(TimeProvider clock) : IHttpErrorMapper<GitHubError>
{
    /// <summary>The longest <see cref="GitHubError.GitHubSaid"/>.</summary>
    internal const int MaxSaidLength = 300;

    /// <summary>The largest Unix time <see cref="DateTimeOffset.FromUnixTimeSeconds"/> accepts, 9999-12-31T23:59:59Z.</summary>
    private const long MaxUnixSeconds = 253_402_300_799;

    /// <summary>GitHub's documented minimum wait after a secondary rate limit that names no time.</summary>
    private static readonly TimeSpan SecondaryLimitWait = TimeSpan.FromSeconds(60);

    public GitHubError Map(HttpError error)
    {
        ArgumentNullException.ThrowIfNull(error);

        return error.Kind switch
        {
            HttpErrorKind.Status => FromStatus(error),
            HttpErrorKind.Timeout => GitHubError.TimedOut(),
            HttpErrorKind.Transport => GitHubError.NotSent(),
            _ => GitHubError.Unreadable("GitHub's answer could not be read.", (int)error.StatusCode == 0 ? null : (int)error.StatusCode),
        };
    }

    /// <summary>
    ///     GitHub's own words: the top-level <c>message</c>, then each <c>errors[]</c> entry as <c>code field: message</c>, or
    ///     the entry itself when it is a string, joined with "; ", on one line of at most <see cref="MaxSaidLength"/>
    ///     characters. <see langword="null"/> for an empty body or one that is not JSON.
    /// </summary>
    internal static string? Summarize(ReadOnlyMemory<byte> body)
    {
        if (body.IsEmpty)
            return null;

        try
        {
            using var document = JsonDocument.Parse(body);
            if (document.RootElement.ValueKind != JsonValueKind.Object)
                return null;

            var parts = new List<string>();
            if (Text(document.RootElement, "message") is { } message)
                parts.Add(message);

            if (document.RootElement.TryGetProperty("errors", out var errors) && errors.ValueKind == JsonValueKind.Array)
            {
                foreach (var entry in errors.EnumerateArray())
                {
                    if (Entry(entry) is { } text)
                        parts.Add(text);
                }
            }

            return parts.Count == 0 ? null : OneLine(string.Join("; ", parts));
        }
        catch (JsonException)
        {
            return null;
        }
    }

    private GitHubError FromStatus(HttpError error)
    {
        var status = (int)error.StatusCode;
        DateTimeOffset? retryAfter = error.GetRetryAfter(clock) is { } wait ? clock.GetUtcNow() + wait : null;
        var exhausted = string.Equals(First(error.Headers, "X-RateLimit-Remaining")?.Trim(), "0", StringComparison.Ordinal);

        // A secondary limit may carry neither header; GitHub then names it only in the body, which is read for this test
        // even when it was cut at 2 KiB.
        var secondary = status is 403 or 429
            && Encoding.UTF8.GetString(error.Body.Span).Contains("secondary rate limit", StringComparison.OrdinalIgnoreCase);

        var kind = status switch
        {
            429 => GitHubErrorKind.RateLimited,
            403 when exhausted || retryAfter is not null || secondary => GitHubErrorKind.RateLimited,
            401 => GitHubErrorKind.Unauthorized,
            403 => GitHubErrorKind.Forbidden,
            404 or 410 => GitHubErrorKind.NotFound,
            408 => GitHubErrorKind.Timeout,
            409 => GitHubErrorKind.Conflict,
            >= 500 and <= 599 => GitHubErrorKind.Server,
            >= 400 and <= 499 => GitHubErrorKind.Validation,
            _ => GitHubErrorKind.Server,
        };

        // GitHub: honour Retry-After when it is present, otherwise wait for X-RateLimit-Reset, otherwise, after a secondary
        // limit, wait at least one minute.
        var retryAt = retryAfter ?? Reset(error.Headers) ?? (secondary ? clock.GetUtcNow() + SecondaryLimitWait : null);
        return GitHubError.FromStatus(status, kind, retryAt) with
        {
            GitHubSaid = error.BodyTruncated ? null : Summarize(error.Body),
        };
    }

    private static string? Entry(JsonElement entry)
    {
        if (entry.ValueKind == JsonValueKind.String)
            return entry.GetString() is { Length: > 0 } text ? text : null;
        if (entry.ValueKind != JsonValueKind.Object)
            return null;

        var head = string.Join(' ', new[] { Text(entry, "code"), Text(entry, "field") }.OfType<string>());
        var message = Text(entry, "message");
        return (head.Length, message) switch
        {
            (0, null) => null,
            (0, _) => message,
            (_, null) => head,
            _ => $"{head}: {message}",
        };
    }

    private static string? Text(JsonElement element, string name) =>
        element.TryGetProperty(name, out var value) && value.ValueKind == JsonValueKind.String && value.GetString() is { Length: > 0 } text
            ? text
            : null;

    /// <summary>Control characters and runs of white space become one space; longer than the cap ends in "…".</summary>
    private static string OneLine(string text)
    {
        var line = new StringBuilder(text.Length);
        foreach (var c in text)
        {
            var blank = char.IsControl(c) || char.IsWhiteSpace(c);
            if (!blank)
                line.Append(c);
            else if (line.Length > 0 && line[^1] != ' ')
                line.Append(' ');
        }

        var trimmed = line.ToString().TrimEnd();
        return trimmed.Length <= MaxSaidLength ? trimmed : string.Concat(trimmed.AsSpan(0, MaxSaidLength - 1), "…");
    }

    private static DateTimeOffset? Reset(IReadOnlyDictionary<string, IReadOnlyList<string>> headers) =>
        long.TryParse(First(headers, "X-RateLimit-Reset"), NumberStyles.None, CultureInfo.InvariantCulture, out var seconds)
        && seconds <= MaxUnixSeconds
            ? DateTimeOffset.FromUnixTimeSeconds(seconds)
            : null;

    /// <summary>The first value of <paramref name="name"/>. The generated client's dictionary ignores case; a hand-built one may not.</summary>
    private static string? First(IReadOnlyDictionary<string, IReadOnlyList<string>> headers, string name)
    {
        if (headers.TryGetValue(name, out var values))
            return values.Count > 0 ? values[0] : null;

        foreach (var header in headers.Where(header => string.Equals(header.Key, name, StringComparison.OrdinalIgnoreCase)))
            return header.Value.Count > 0 ? header.Value[0] : null;

        return null;
    }
}
```

```csharp
using System.Collections.Concurrent;

namespace Daedalus.Tests.Unit.Infrastructure.Services.GitHub;

/// <summary>One request as it was sent: its headers and body are copied before the client disposes it.</summary>
internal sealed record SentRequest(HttpMethod Method, Uri Uri, IReadOnlyDictionary<string, string> Headers, string? Body);

/// <summary>
///     The innermost handler of a test pipeline. It records every attempt, thread-safely, and answers with
///     <paramref name="respond"/>, which may wait on the attempt's token to stand in for a slow GitHub.
/// </summary>
internal sealed class RecordingHandler(Func<HttpRequestMessage, CancellationToken, Task<HttpResponseMessage>> respond) : HttpMessageHandler
{
    private readonly ConcurrentQueue<SentRequest> _sent = new();

    public IReadOnlyList<SentRequest> Sent => [.. _sent];

    public int Count => _sent.Count;

    public static RecordingHandler Answering(Func<HttpRequestMessage, HttpResponseMessage> respond) =>
        new((request, _) => Task.FromResult(respond(request)));

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        var body = request.Content is null ? null : await request.Content.ReadAsStringAsync(cancellationToken).ConfigureAwait(false);
        var headers = request.Headers.ToDictionary(header => header.Key, header => string.Join(", ", header.Value), StringComparer.OrdinalIgnoreCase);
        _sent.Enqueue(new SentRequest(request.Method, request.RequestUri!, headers, body));
        return await respond(request, cancellationToken).ConfigureAwait(false);
    }
}
```

```csharp
    private async Task<Result<string, GitHubError>> ReadDefaultBranchAsync(RepoRef repo, CancellationToken ct)

    private async Task<CategoryResult<CommitSummary>> ReadCommitsAsync(RepoRef repo, DateTime sinceUtc, CancellationToken ct)
    {

        if (branch.IsFailure)
            return Unavailable<CommitSummary>(repo, "commits", branch.Error);

        var listed = await CallAsync(
            (auth, c) => _reads.ListCommitsAsync(repo.Owner, repo.Name, branch.Value, FormatIso(sinceUtc), _options.MaxItemsPerCategory, auth, UserAgent, c),
            ct).ConfigureAwait(false);
        if (listed.IsFailure)
            return Unavailable<CommitSummary>(repo, "commits", listed.Error);

        var items = new List<CommitSummary>(listed.Value.Count);
        foreach (var dto in listed.Value)
        {
            if (dto is not { Sha: { } sha, Commit.Message: { } message })
                return Unavailable<CommitSummary>(repo, "commits", Unexpected($"listing {repo}'s commits"));

            var author = dto.Commit.Author;
            var committedAt = TryParseTimestamp(author?.Date, out var date) ? date : sinceUtc;
            items.Add(new CommitSummary(sha, message, author?.Name ?? "", committedAt));
        }

        return BuildCategoryResult(items, listed.Value.Count);
    }

    /// <summary>
    ///     Builds the category result. <paramref name="rawCount"/> is the length of the array GitHub returned before any
    ///     client-side filtering: truncation must be judged against what the page could have held, not against what
    ///     survived filtering, or a full page that filters down to a handful reports as complete.
    /// </summary>
    private CategoryResult<T> BuildCategoryResult<T>(List<T> items, int rawCount)
    {
        var truncated = rawCount >= _options.MaxItemsPerCategory;
        IReadOnlyList<T> taken = items.Count > _options.MaxItemsPerCategory
            ? items.Take(_options.MaxItemsPerCategory).ToList()
            : items;

        return CategoryResult<T>.Ok(taken, truncated);
    }

    /// <summary>
    ///     Reads up to <see cref="MaxScanPages"/> pages of 100 and stops at the first short page. More than that is a
    ///     failure rather than a silent cut, because a marker scan that stopped early would report "not found" for
    ///     something that exists. <paramref name="read"/> returns <see langword="null"/> for an item missing a field.
    /// </summary>
    private async Task<Result<IReadOnlyList<T>, GitHubError>> ScanAsync<TDto, T>(
        Func<int, string, CancellationToken, Task<Result<IReadOnlyList<TDto>, GitHubError>>> readPage,
        string what,
        Func<TDto, T?> read,
        CancellationToken ct)
        where T : class
    {
        var found = new List<T>();
        for (var page = 1; page <= MaxScanPages; page++)
        {
            var current = page;
            var listed = await CallAsync((auth, c) => readPage(current, auth, c), ct).ConfigureAwait(false);
            if (listed.IsFailure)
                return Result<IReadOnlyList<T>, GitHubError>.Failure(listed.Error);

            foreach (var dto in listed.Value)
            {
                if (read(dto) is not { } item)
                    return Result<IReadOnlyList<T>, GitHubError>.Failure(Unexpected(what));

                found.Add(item);
            }

            if (listed.Value.Count < ScanPageSize)
                return Result<IReadOnlyList<T>, GitHubError>.Success(found);
        }

        return Result<IReadOnlyList<T>, GitHubError>.Failure(GitHubError.Refused(
            $"{what}: the scan read the {MaxScanPages * ScanPageSize}-item cap and stops rather than read further."));
    }

    /// <summary>
    ///     Every call with an answer goes through here: the token first, so a missing one sends nothing, then the call. A
    ///     Polly rejection, which no generated client maps, becomes a <see cref="GitHubError"/> too (ruling P13).
    /// </summary>
    private async Task<Result<T, GitHubError>> CallAsync<T>(
        Func<string, CancellationToken, Task<Result<T, GitHubError>>> call, CancellationToken ct)
    {
        var token = _tokens.GetToken();
        if (token.IsFailure)
            return Result<T, GitHubError>.Failure(GitHubError.NoToken(token.Error));

        try
        {
            return await call("Bearer " + token.Value, ct).ConfigureAwait(false);
        }
        catch (TimeoutRejectedException)
        {
            return Result<T, GitHubError>.Failure(GitHubError.TimedOut());
        }
        catch (ExecutionRejectedException ex)
        {
            LogRejected(_logger, ex.GetType().Name);
            return Result<T, GitHubError>.Failure(GitHubError.NotSent());
        }
    }

    /// <summary>As <see cref="CallAsync{T}"/>, for a write without an answer; success is <paramref name="confirmation"/>.</summary>
    private async Task<Result<string, GitHubError>> WriteAsync(
        Func<string, CancellationToken, Task<UnitResult<GitHubError>>> send, string confirmation, CancellationToken ct)
    {
        var token = _tokens.GetToken();
        if (token.IsFailure)
            return Result<string, GitHubError>.Failure(GitHubError.NoToken(token.Error));

        UnitResult<GitHubError> sent;
        try
        {
            sent = await send("Bearer " + token.Value, ct).ConfigureAwait(false);
        }
        catch (TimeoutRejectedException)
        {
            return Result<string, GitHubError>.Failure(GitHubError.TimedOut().ForWrite());
        }
        catch (ExecutionRejectedException ex)
        {
            LogRejected(_logger, ex.GetType().Name);
            return Result<string, GitHubError>.Failure(GitHubError.NotSent().ForWrite());
        }

        return sent.IsSuccess
            ? Result<string, GitHubError>.Success(confirmation)
            : Result<string, GitHubError>.Failure(sent.Error.ForWrite());
    }

    /// <summary>
    ///     <see cref="IHttpClientFactory.CreateClient"/> returns a new <c>HttpClient</c> per call, so setting its base address
    ///     here, before anything is sent, changes nothing shared. The trailing slash keeps a GitHub Enterprise path such as
    ///     <c>/api/v3</c>, since every route is relative.
    /// </summary>
    private HttpClient Rooted(HttpClient http)
    {
        // A char, not a "/" literal: Sonar S1075 reads a string literal here as a hard-coded path.
        http.BaseAddress = new Uri(_options.ApiUrl.TrimEnd('/') + '/', UriKind.Absolute);
        return http;
    }
```

```csharp
    public async Task<Result<PullRequestResult>> CreatePullRequestAsync(
        string repositoryUrl,
        string featureBranch,
        string baseBranch,
        string title,
        string description,
        CancellationToken ct = default)
    {
        var token = await authProvider.GetAuthTokenAsync(RepositoryPlatform.AzureDevOps, ct).ConfigureAwait(false);
        if (token.IsFailure)
            return Result<PullRequestResult>.Failure(token.Error);

        if (!TryParse(repositoryUrl, out var organization, out var project, out var repository))
            return Result<PullRequestResult>.Failure("Invalid Azure DevOps URL format");

        // Per call, never on the shared client's DefaultRequestHeaders: two runs opening pull requests at once must each
        // send their own token.
        var authorization = "Basic " + Convert.ToBase64String(Encoding.ASCII.GetBytes($":{token.Value}"));
        var body = new AzureDevOpsCreatePullRequestBody($"refs/heads/{featureBranch}", $"refs/heads/{baseBranch}", title, description, []);

        Result<AzureDevOpsPullRequestDto, HttpError> created;
        try
        {
            // A path segment of a parsed URL is still escaped, and the route escapes again, so each one is unescaped first.
            created = await _api.CreatePullRequestAsync(
                Uri.UnescapeDataString(organization), Uri.UnescapeDataString(project), Uri.UnescapeDataString(repository),
                ApiVersion, body, authorization, ct).ConfigureAwait(false);

        {
            return Result<PullRequestResult>.Failure("Azure DevOps API error: the request timed out");
        }
        catch (ExecutionRejectedException ex)
        {
            LogRejected(logger, ex.GetType().Name);
            return Result<PullRequestResult>.Failure("Azure DevOps API error: the request was not sent");
        }

        if (created.IsFailure)
        {
            LogCreateFailed(logger, created.Error.Kind, (int)created.Error.StatusCode);
            return Result<PullRequestResult>.Failure(Describe(created.Error));
        }

        if (created.Value is not { PullRequestId: { } id, Url: { } url })
            return Result<PullRequestResult>.Failure("Azure DevOps API error: the answer was not in the expected shape");

            PullRequestUrl = url,
            WebUrl = $"https://dev.azure.com/{organization}/{project}/_git/{repository}/pullrequest/{id}",
            Status = PullRequestStatus.Open,
        };

        LogCreated(logger, result.WebUrl);
        return Result<PullRequestResult>.Success(result);

    private static bool TryParse(string repositoryUrl, out string organization, out string project, out string repository)
    {
        organization = project = repository = string.Empty;
        if (!Uri.TryCreate(repositoryUrl, UriKind.Absolute, out var uri))
            return false;

        var segments = uri.AbsolutePath.Split('/', StringSplitOptions.RemoveEmptyEntries);
        if (segments.Length < 4 || !string.Equals(segments[2], "_git", StringComparison.Ordinal))
            return false;

        (organization, project, repository) = (segments[0], segments[1], segments[3]);
        return true;
    }

        HttpErrorKind.Timeout => "Azure DevOps API error: the request timed out",
        HttpErrorKind.Transport => "Azure DevOps API error: Azure DevOps could not be reached",
        _ => "Azure DevOps API error: the answer could not be read",
    };
```

```csharp
using System.Net;

namespace Daedalus.Infrastructure.Services.GitHub;

/// <summary>
///     The process-wide store behind <see cref="GitHubConditionalCacheHandler"/>: at most <see cref="Capacity"/> answers
///     that carried an ETag, the least recently used evicted first. In memory only, so a restart costs one full request per
///     URL (spec D4).
/// </summary>
internal sealed class GitHubConditionalCache
{
    /// <summary>The most answers kept.</summary>
    public const int Capacity = 200;

    /// <summary>The largest body kept, 256 KiB. A larger answer passes through unstored, so the cache stays bounded in bytes.</summary>
    public const int MaxEntryBytes = 256 * 1024;

    private readonly Lock _gate = new();
    private readonly Dictionary<string, LinkedListNode<Entry>> _entries = new(StringComparer.Ordinal);
    private readonly LinkedList<Entry> _recency = new();

    public int Count
    {
        get
        {
            lock (_gate)
            {
                return _entries.Count;
            }
        }
    }

    /// <summary>The entry for <paramref name="key"/>, now the most recently used, or <see langword="null"/>.</summary>
    public Entry? Find(string key)
    {
        lock (_gate)
        {
            if (!_entries.TryGetValue(key, out var node))
                return null;

            _recency.Remove(node);
            _recency.AddFirst(node);
            return node.Value;
        }
    }

    /// <summary>Stores <paramref name="entry"/> as the most recently used, replacing one with its key, and evicts past the cap.</summary>
    public void Store(Entry entry)
    {
        ArgumentNullException.ThrowIfNull(entry);

        lock (_gate)
        {
            if (_entries.Remove(entry.Key, out var replaced))
                _recency.Remove(replaced);

            _entries[entry.Key] = _recency.AddFirst(entry);

            while (_entries.Count > Capacity)
            {
                var oldest = _recency.Last!;
                _recency.RemoveLast();
                _entries.Remove(oldest.Value.Key);
            }
        }
    }

    /// <summary>One stored answer: its validator, its body and its content type.</summary>
    internal sealed record Entry(string Key, string ETag, byte[] Body, string? ContentType);
}

/// <summary>
///     Answers a repeated GitHub read from <see cref="GitHubConditionalCache"/> when GitHub says nothing changed. A GET whose
///     URL has a stored answer is sent with <c>If-None-Match</c>; a <c>304</c> comes back as a <c>200</c> with the stored body;
///     a <c>200</c> with an <c>ETag</c> is stored. Everything else passes through and is not stored: errors, a <c>200</c>
///     without an <c>ETag</c>, and every write. A <c>304</c> to an authenticated conditional request costs no primary rate
///     limit, and GitHub sends one only when the resource is unchanged.
/// </summary>
/// <remarks>
///     The key is the method and the full URL, with no identity: the process holds a single GitHub token, which
///     <see cref="GitHubTokenSource"/> reads from one environment variable, so every caller may see every stored answer.
///     A second token would need the identity in the key. The entry found before sending is the one replayed, so an
///     eviction while the request is in flight cannot let a <c>304</c> through.
/// </remarks>
internal sealed class GitHubConditionalCacheHandler(GitHubConditionalCache cache) : DelegatingHandler
{
    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        if (request.Method != HttpMethod.Get || request.RequestUri is null)
            return await base.SendAsync(request, cancellationToken).ConfigureAwait(false);

        var key = "GET " + request.RequestUri.AbsoluteUri;
        var stored = cache.Find(key);
        if (stored is not null)
            request.Headers.TryAddWithoutValidation("If-None-Match", stored.ETag);

        var response = await base.SendAsync(request, cancellationToken).ConfigureAwait(false);

        if (response.StatusCode == HttpStatusCode.NotModified && stored is not null)
            return Replay(response, stored);

        if (response.StatusCode == HttpStatusCode.OK
            && response.Headers.ETag is { } etag
            && response.Content.Headers.ContentLength is null or <= GitHubConditionalCache.MaxEntryBytes)
        {
            // ReadAsByteArrayAsync buffers the content, so the client still reads the whole body after this. A body without
            // a declared length is checked once read.
            var body = await response.Content.ReadAsByteArrayAsync(cancellationToken).ConfigureAwait(false);
            if (body.Length <= GitHubConditionalCache.MaxEntryBytes)
                cache.Store(new GitHubConditionalCache.Entry(key, etag.ToString(), body, response.Content.Headers.ContentType?.ToString()));
        }

        return response;
    }

    private static HttpResponseMessage Replay(HttpResponseMessage notModified, GitHubConditionalCache.Entry stored)
    {
        var replay = new HttpResponseMessage(HttpStatusCode.OK)
        {
            RequestMessage = notModified.RequestMessage,
            Version = notModified.Version,
            Content = new ByteArrayContent(stored.Body),
        };

        foreach (var header in notModified.Headers)
            replay.Headers.TryAddWithoutValidation(header.Key, header.Value);

        if (stored.ContentType is not null)
            replay.Content.Headers.TryAddWithoutValidation("Content-Type", stored.ContentType);

        notModified.Dispose();
        return replay;
    }
}
```

```csharp
using System.Diagnostics.Metrics;
using System.Globalization;

namespace Daedalus.Infrastructure.Services.GitHub;

/// <summary>
///     Reports how much of GitHub's rate limit is left, from every answer's <c>X-RateLimit-Remaining</c>, as the gauge
///     <see cref="RemainingName"/>, tagged with the limit's resource, such as <c>core</c> or <c>search</c>. It sits inside
///     the retries, so every attempt counts, and below the conditional cache, so a <c>304</c> is seen too. It measures and
///     never throttles (spec D5).
/// </summary>
/// <remarks>
///     <b>No content.</b> The only tag is GitHub's resource name: no path, repository, token or status. The meter is under
///     <c>daedalus.*</c>, which the service defaults collect.
/// </remarks>
public sealed class GitHubRateLimitObserver : DelegatingHandler
{
    /// <summary>The meter, under the <c>daedalus.*</c> wildcard the service defaults subscribe to.</summary>
    public const string MeterName = "daedalus.github";

    /// <summary>The gauge's name.</summary>
    public const string RemainingName = "daedalus.github.ratelimit.remaining";

    /// <summary>The one tag: GitHub's <c>X-RateLimit-Resource</c>, or <c>unknown</c>.</summary>
    public const string ResourceTag = "daedalus.github.resource";

    private static readonly Meter Meter = new(MeterName);

    private static readonly Gauge<long> Remaining = Meter.CreateGauge<long>(
        RemainingName, unit: "{request}", description: "Requests left in the current GitHub rate-limit window, per resource");

    protected override async Task<HttpResponseMessage> SendAsync(HttpRequestMessage request, CancellationToken cancellationToken)
    {
        var response = await base.SendAsync(request, cancellationToken).ConfigureAwait(false);
        Record(response);
        return response;
    }

    private static void Record(HttpResponseMessage response)
    {
        if (!response.Headers.TryGetValues("X-RateLimit-Remaining", out var values)
            || !long.TryParse(values.FirstOrDefault(), NumberStyles.None, CultureInfo.InvariantCulture, out var remaining))
        {
            return;
        }

        var resource = response.Headers.TryGetValues("X-RateLimit-Resource", out var names) ? names.FirstOrDefault() : null;
        Remaining.Record(remaining, new KeyValuePair<string, object?>(ResourceTag, string.IsNullOrWhiteSpace(resource) ? "unknown" : resource));
    }
}
```

```markdown
#### The GitHub client

Every GitHub call goes through `GitHubApi`, over two ZeroAlloc.Rest clients generated from `IGitHubRestApi`:

- **Reads** use the `GitHub.Read` client. They retry on 5xx, 408 and timeouts. A 429 is not retried: it fails at once
  as a rate limit with the time it lifts. A repeated read is sent with `If-None-Match`, and GitHub's `304 Not Modified`,
  which costs no rate limit, is answered from an in-memory cache of 200 answers of at most 256 KiB each. A restart
  empties it.
- **Writes**, comments, labels, closes, issues and pull requests, use the `GitHub.Write` client and are sent **exactly
  once**, never retried: GitHub has no idempotency keys, so a retried write can land twice. The Azure DevOps pull request
  create follows the same rule.
- **Errors** are a typed `GitHubError` with a kind, such as `RateLimited`, `NotFound` or `Forbidden`, the status, and
  for a rate limit the time it lifts. A 429, a 403 with `X-RateLimit-Remaining: 0`, a 403 with `Retry-After` and a 403
  whose body names a secondary rate limit are all rate limits. An agent tool also shows a one-line summary of what
  GitHub said, at most 300 characters; logs, run errors and the publish node never repeat GitHub's response body. A
  write that failed after it may have reached GitHub says so.
- **The remaining rate limit** is the gauge `daedalus.github.ratelimit.remaining`, see "Metrics". Nothing throttles
  before GitHub refuses.
```

```markdown
## External HTTP APIs

An external REST API, as GitHub and Azure DevOps are, is a ZeroAlloc.Rest client behind a facade:

- **An internal `[ZeroAllocRestClient(MaxErrorBodyBytes = ...)]` interface**, one method per endpoint, with relative
  routes and no leading slash, so a base address's own path is kept. Read no more error body than you use: `0` for Azure
  DevOps, which uses none, and 2 KiB for GitHub, whose body is summarised for the agent only.
- **A source-generated `JsonSerializerContext`** over DTOs whose fields are all nullable, passed as
  `new SystemTextJsonSerializer(Context.Default)`. No reflection serialization and no IL2026 suppression.
- **A typed error and an `[ErrorMapper]`**, as `GitHubError` and `GitHubErrorMapper`. The message is built from the
  kind, the status and the retry time, never from a body or an exception's message, because it reaches logs, run errors
  and span status. What the API said goes into a separate, bounded field, `GitHubSaid`, that only agent tools render
  through `ForAgent()`.
- **Credentials per call**, as a `[Header("Authorization")]` parameter. Never set a token on a client's
  `DefaultRequestHeaders`: an `HttpClient` can be shared, and two calls at once would send each other's token.
- **The facade** owns everything that is not HTTP, such as paging, required fields and which failure means "not there".
  It creates its clients from `IHttpClientFactory` and sets their `BaseAddress` before anything is sent.
- **Handlers** for what the generated client cannot see, such as success headers. GitHub's read client carries
  `GitHubConditionalCacheHandler` outside the resilience handler and `GitHubRateLimitObserver` inside it.

**Testing.** A generated client disposes its request when the call returns, so a test handler reads the body when the
request is sent, as `StubHandler` and `RecordingHandler` do. `GitHubHost` builds the real `AddGitHubApi` pipelines over a
test handler with zero retry delays; a standard pipeline's options are named `{client}-standard`.
```
