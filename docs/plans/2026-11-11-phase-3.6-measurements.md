## Reading the numbers

- **The comparison is not like for like in the machine.** The JIT figures come from the 12-core agent VM, the native
  ones from a GitHub runner, both limited to 2 CPUs. Phase 3.1 measured about 5 % noise at the median and 10 % at
  p90 on one machine; a different machine adds more, so read the percentages as the size of the effect, not as exact.
- **Start-up** falls most for the CLI and the Api, where the JIT build spent its time loading the shared framework and
  compiling. The sandbox host was already native since phase 3.1's JIT baseline was taken from the image of that
  commit, which shipped the JIT host; its remaining 325 ms is dominated by the container and the SDK image.
- **The Api image** is 75.6 MiB because it is `runtime-deps` plus ICU plus one executable, where the JIT image held the
  `aspnet` runtime. Its app size is 78.1 MiB, down from 104.5.
- **The sandbox image** is 617 MiB against 1375 MiB: this phase's image uses the .NET 11 SDK image that `main`
  moved to, which is smaller than the SDK 10 one. Part of that drop is the SDK, not Native AOT. The host itself is
  larger as a native binary (19.8 MiB against 6.6), as expected.
- **Api memory under load** was read after the harness's 200 requests at concurrency 10; the database holds no rows.
