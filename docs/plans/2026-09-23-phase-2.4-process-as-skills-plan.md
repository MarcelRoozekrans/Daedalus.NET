# Phase 2.4 — The Process as Skills: Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** A manufacturing run can be started through a real surface with a stated intent, runs
against a pinned, immutable snapshot of its skills, role charters and standing instructions, and
proposes improvements to those standing instructions that only a human can accept.

**Architecture:** Two repositories. Thalos.NET 0.10.0 gains content-addressed skill history, role
charters composed onto a config-owned tool envelope, agent-definition revisions under one
`AgentId`, a write-once run manifest, and a dispatcher that honours it. Daedalus adopts that,
moves the squad roles into `roles/*.md`, adds `POST/GET /api/workflow-runs` and `manufacture__start`,
and adds a `retrospect` node whose `AGENT.md` proposal is written by host code only when a human
resumes the gate with `applyStandingInstructions: true`.

**Tech Stack:** .NET 10 / C# 13, Thalos.NET 0.9.0 → 0.10.0, `ZeroAlloc.Results`, `ZeroAlloc.ORM`
raw-SQL migrations (Thalos), EF Core 10 + PostgreSQL (Daedalus), xUnit 2.9.3 + AwesomeAssertions
9.6.0 + NSubstitute, Testcontainers.PostgreSql.

**Spec:** `docs/plans/2026-09-23-phase-2.4-process-as-skills-design.md` — read the
**Amendments from plan research** section; it overrides the body where they differ.

private static readonly FrozenSet<string> ScalarKeys = new[] { "name", "description", "model" }.ToFrozenSet(StringComparer.Ordinal);
private static readonly FrozenSet<string> SequenceKeys = new[] { "skills" }.ToFrozenSet(StringComparer.Ordinal);
private static readonly FrozenDictionary<string, string> Forbidden = new Dictionary<string, string>(StringComparer.Ordinal)
{
    ["tools"] = "a charter may not name tools: a role's tool list is its security envelope and stays in configuration, where changing it needs a reviewed deploy",
}.ToFrozenDictionary(StringComparer.Ordinal);

public static Result<RoleCharter, AgentError> Parse(string sourcePath, string expectedRole, string text, DateTimeOffset updatedAt)
{
    var parsed = Frontmatter.Parse(text, ScalarKeys, SequenceKeys, Forbidden);
    if (parsed.IsFailure)
        return Result<RoleCharter, AgentError>.Failure(AgentError.SkillValidationFailed($"{sourcePath}: {parsed.Error}"));

    var fm = parsed.Value;
    if (!fm.Scalars.TryGetValue("name", out var name) || !SkillName.TryParse(name, out var role) || role.Value != expectedRole)
        return Result<RoleCharter, AgentError>.Failure(AgentError.SkillValidationFailed($"{sourcePath}: name must be '{expectedRole}'"));
    if (!fm.Scalars.TryGetValue("description", out var description) || string.IsNullOrWhiteSpace(description))
        return Result<RoleCharter, AgentError>.Failure(AgentError.SkillValidationFailed($"{sourcePath}: description is required"));
    if (string.IsNullOrWhiteSpace(fm.Body))
        return Result<RoleCharter, AgentError>.Failure(AgentError.SkillValidationFailed($"{sourcePath}: the body is the role's instructions and must not be empty"));

    return Result<RoleCharter, AgentError>.Success(new RoleCharter
    {
        Role = role.Value,
        Description = description.Trim(),
        Instructions = fm.Body,
        Model = fm.Scalars.TryGetValue("model", out var model) ? model : null,
        Skills = fm.Sequences.TryGetValue("skills", out var skills) ? skills : [],
        SourcePath = sourcePath,
        ContentHash = SkillFileLoader.Hash(fm.Normalized),
        UpdatedAt = updatedAt,
    });
}
