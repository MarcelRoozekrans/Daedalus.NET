## Rulings

No separate list exists. Phase 2.1 was designed, built and merged on one day with the owner in the session, and
its decisions went into the design doc and the close-out commit as they were made. Any decision taken during
implementation without the owner was not recorded apart from those, and is not reconstructed here: a list written
a month later would be a guess presented as a record.

## Where the phase's decisions are recorded

- **Placement, decided 2026-09-21:** the design's "Placement" section. Thalos.NET holds the generic git write
  contract, local git on LibGit2Sharp, and a pull request publisher abstraction. Daedalus implements the publisher
  over its existing `IPullRequestFactory` dispatcher and owns the `GitHubApi` consolidation, the tool registration
  and the `developer` policy binding. Thalos never references Daedalus. The phase therefore spanned two repositories.
- **Approach:** the design's "Approach" sections 1 to 4: one GitHub HTTP client, branch creation in Thalos, the
  agent tool surface, and the authorization boundary.
- **What shipped and was carried forward:** the close-out commit `b8a31bdc` and the phase 2.1 row in
  `docs/planning/ROADMAP.md`.
