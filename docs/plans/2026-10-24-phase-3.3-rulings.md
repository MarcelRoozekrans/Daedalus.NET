The phase ran subagent-driven on `phase/3.3-own-llm-clients` from `main` `88cf0433`, across four repositories:
ZeroAlloc.Resilience, ZeroAlloc.Rest, Thalos.NET and Daedalus. Each task had a fresh implementer and a fresh reviewer;
the controller ran the outward steps itself: the PRs, the recording, the native run, the upstream comment and the live
runs. The plan was scanned against the spec before any task ran; the scan found one ordering conflict and two blocked
steps, ruled on as R1 to R3. Every decision taken on the owner's behalf is listed below with what it costs if it is
wrong, so it can be checked and reversed.

## Owner decisions

Owner decisions are the owner's to weigh, so they carry no cost line.

2026-10-24, at the brainstorm, in the spec's "Owner decisions":

- **Streaming lives in ZeroAlloc.Rest:** the generator learns `IAsyncEnumerable<T>` over `text/event-stream`.
- **This phase builds the ZeroAlloc packages;** the owner merges and releases them, Thalos and Daedalus consume the
  release.
- **Both clients live in the ZeroAlloc.Rest repo,** `src/ZeroAlloc.Rest.Anthropic` and `src/ZeroAlloc.Rest.Ollama`,
  at the repo's one version.
- **API scope is what Thalos and Daedalus use:** messages create and stream, text, tools, `cache_control` with a TTL,
  usage with the cache split, stop reasons, error mapping and retries.
- **Recorded transcripts,** replayed in CI, with no secret in the files.
- **`AgentFactory` goes through Thalos' `IChatClientProvider`,** one Anthropic path.
- **OllamaSharp leaves the AppHost too:** a plain Ollama container plus a model pull replace
  `CommunityToolkit.Aspire.Hosting.Ollama`.
- **Stream retries live in ZeroAlloc.Resilience,** retrying until the first item and never after.
- **Caller-set cache markers are dropped;** the translator places every breakpoint from `PromptCacheHints`, and
  Thalos 0.20.0's BREAKING CHANGE footer names it.
- **The native proof:** "Application started", then one native turn. Amended on 2026-10-31, below.

## Rulings

Pre-flight, controller, 2026-10-25:

1. **R1:** Task 10 runs after Task 9. If Task 9 is still waiting on the recording, Task 10 creates
   `samples/ZeroAlloc.Rest.Clients.AotSmoke` with the embed call only and Task 9 adds the Anthropic calls: whoever
   comes first creates the shared sample.
   *Cost if wrong:* one moved file.
2. **R2:** `ANTHROPIC_API_KEY` was unset; Task 8 Step 4, the recording, is an outward, paid step the owner enables.
   Task 10 ran meanwhile, and Tasks 9 and 12 waited.
   *Cost if wrong:* wall clock only.
3. **R3:** one implementer at a time across the repositories; Part B continued while G1 was with the owner.
   *Cost if wrong:* wall clock only.

ZeroAlloc.Resilience and ZeroAlloc.Rest SSE, Tasks 1 to 5:

4. **R4:** RCS1194 on `HttpErrorException` stays suppressed, with a scoped disable and restore around each type and its
   rationale, as Saga, ORM and Mediator.Authorization do. The rule's parameterless and message-only constructors would
   build an exception with a null `Error`, breaking the type's invariant: the analyzer is wrong for this type.
   *Cost if wrong:* the owner may prefer the constructors.
5. **R5:** an SSE event with no `event:` line has type `message`, as WHATWG and `System.Net.ServerSentEvents` define.
   OpenAI-style data-only streams would otherwise be skipped silently.
   *Cost if wrong:* one behaviour flip before release.
6. **R6:** ZRA008, a shape-two stream method with no `[EventType]`, and ZRA007, `[EventStream]` on a method that is
   not `IAsyncEnumerable<T>`, stay errors. They block silent misbehaviour on new attributes only.
   *Cost if wrong:* two diagnostics to relax.
7. **R7:** the brief's Red, "drop `[Retry]`", does not compile; `MaxAttempts = 1` and `DroppingContent("")` replace
   it, each turning its test red at a named assertion.
   *Cost if wrong:* none; the plan's Red was impossible as written.
8. **R8:** the SSE PR opened early as ZeroAlloc.Rest#492, the first half of the stack, so `aot-smoke` gave feedback
   early; the clients PR stacked on it.
   *Cost if wrong:* none, the owner merges.

ZeroAlloc.Rest.Anthropic and ZeroAlloc.Rest.Ollama, Tasks 6 to 11b:

9. **R9:** ZeroAlloc.Rest 3.4.0 shipped SSE only, so the clients ship in the next release, a `feat:` and so expected
   3.5.0; Tasks 12 and 17 pin that version instead of 3.4.0.
   *Cost if wrong:* one version number.
10. **R10:** `IAnthropicMessagesApi` is internal, against the plan's "public interface". The generated public
    `AddIAnthropicMessagesApi` registers a client with no key, version, timeout or retries; `AnthropicClient` is the
    API.
    *Cost if wrong:* someone wanting the raw typed interface gets none.
11. **R11:** the differences from SDK 13.1.0's retries are kept: one 60 s cap for backoff and `retry-after`, because
    `RetryPolicy` has one `MaxDelayMs` and 8 s would truncate `retry-after`; the library's jitter, up to +50 %; 408,
    409, timeouts and connection errors not retried, per the plan's retry rule; `x-should-retry` and
    `retry-after-ms` ignored.
    *Cost if wrong:* fewer retries on transport blips than the SDK made.
12. **R12:** the plan's review focus forbids the key and header values in errors, not header names, so Anthropic's
    real 401 text "invalid x-api-key" passes through unchanged.
    *Cost if wrong:* a header name in an error message.
13. **R13:** the recorder, the native turn and the live runs run with the key injected from the owner's secret store
    for that one command; the key is never written to a file or printed.
    *Cost if wrong:* none.
14. **R14:** a 200 embed response without `embeddings` is a deserialization failure, not a success with null: the
    member is `required`.
    *Cost if wrong:* a stricter client.
15. **R20:** Task 11b targets `net8.0;net10.0` only, not `net9.0`, which is out of support.
    *Cost if wrong:* one more target framework later.

Thalos 0.20.0, Tasks 12 to 16:

16. **R15:** Task 12 reads the SDK adapter of the version Thalos shipped, 13.3.0, not 13.1.0: the behaviour to keep is
    what users had.
    *Cost if wrong:* none.
17. **R16:** system messages in the middle of a conversation are lifted into the top-level system prompt in order; the
    Messages API has no system role inside `messages`.
    *Cost if wrong:* a prompt-order difference for callers that interleave system messages.
18. **R17:** the adapter reproduces SDK 13.3.0's tool-schema transform through M.E.AI's `AIJsonSchemaTransformCache`

    *Cost if wrong:* schemas a strict API would have accepted get reshaped, as before.
19. **R18:** a tool result is sent as text, several MCP text items joined by newlines. Content blocks in
    `tool_result` need a ZeroAlloc.Rest.Anthropic model change, filed as ZeroAlloc.Rest#518; images are out of scope.
    *Cost if wrong:* a model sees joined text instead of separate blocks, as with the SDK.
20. **R19:** `temperature` and `top_p` are mapped as the plan says, though SDK 13.3.0 dropped them; Thalos sets
    neither.
    *Cost if wrong:* none today.
21. **R21:** Task 13 also removes the `Anthropic` package version and reference, since Task 12 kept them to build in
    two steps; the Thalos PR squash-merges, so its BREAKING CHANGE footer stays true.
    *Cost if wrong:* none.
22. **R22:** after ZeroAlloc.Rest 3.6.0, Task 14b bumps Thalos to it and restores `net8.0;net10.0` on both adapters;
    Task 14 built `net10.0` only until then.
    *Cost if wrong:* none.
23. **R23:** the native probe references Thalos.NET.Ollama and exercises it, as the plan says.
    *Cost if wrong:* one more ILC input in CI.
24. **R24:** the probe's Reds were verified by a changed JIT probe line seen failing: `NativeProbeTests` compares the
    JIT output with the golden, so the change turns that test red. The native half's pairing is confirmed in CI.
    *Cost if wrong:* the native half's pairing is confirmed only in CI.
25. **R25:** `ab118d7`'s body overstates "seen to fail" for the probe Reds. It is merged history and was not rewritten;

    *Cost if wrong:* one imprecise line in history.

    projects, and layering does not depend on the target framework. The missing `net8.0` CI test leg is filed as

    *Cost if wrong:* a `net8.0`-only defect in another package goes unseen until a consumer hits it.

Daedalus on Thalos 0.20.0, Tasks 17 to 21:
