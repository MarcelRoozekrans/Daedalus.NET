# Phase 2.9: Observability, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A manufacture run is debuggable from the Aspire dashboard or any OTLP collector. Each step of a run is its
own trace, found by `thalos.run.id` and linked back to the request that started the run. The run's durations, outcomes
and token spend are metrics.

**Architecture:** Two repositories change, in dependency order. A third is only checked.

- **Part 0: ZeroAlloc.Telemetry, a verification gate.** The feature the spec's step A6 asks for, error status from a
  failed `Result`, shipped in 1.9.0 as `[Trace(ErrorWhen = ..., ErrorDescription = ...)]` (finding F1). Part 0
  confirms the published 1.12.0 package carries it. No code and no release.
- **Part A: Thalos.NET 0.15.0.**
  - A `thalos.workflow` source and meter, in `WorkflowTelemetry`.
  - A hand-written `thalos.workflow.dispatch` span per node dispatch. `WorkflowNodeDispatcher` is sealed, so no proxy
    can reach it. The span carries the run, node, seq, process and outcome, and an `ActivityLink` to the run's start.
  - The start's W3C traceparent, persisted in a new nullable column, `workflow_run.trace_parent`.
  - Generated ZeroAlloc.Telemetry proxies on `IWorkflowHostAction` and on the state-changing `IWorkflowStore` methods.
    `ErrorWhen = "IsFailure"` marks a failed `Result` as an error.
  - Five metrics: runs started, runs finished, dispatch duration, host-action duration and run-tool duration.
  - A shared `TelemetryCapture` test fixture in `Thalos.NET.Testing`, which Daedalus's tests reuse.
- **Part B: Daedalus.**
  - It subscribes to `thalos`, `thalos.workflow`, `ZeroAlloc.Mediator` and `daedalus.*`, and to ASP.NET Core and
    HttpClient. Health and alive endpoints are filtered out.
  - It exports traces, metrics and logs over OTLP only when `OTEL_EXPORTER_OTLP_ENDPOINT` is set.
  - It adds `[Instrument]` proxies on its two run seams, a task-id tag on the request span, and a token counter.
  - It deletes the dead OpenTelemetry configuration and packages.

**Tech Stack:** .NET 10 / C# 13; Thalos multi-targets `net8.0` and `net10.0`; `Thalos.NET.Workflow.Orm` targets
`net10.0` only. `System.Diagnostics` `ActivitySource` and `Meter`. ZeroAlloc.Telemetry 1.12.0 source-generated proxies.
OpenTelemetry .NET 1.17.0: OTLP, ASP.NET Core and HttpClient instrumentation, and the in-memory exporter for tests.
ZeroAlloc.ORM over PostgreSQL. ZeroAlloc.Results. xUnit, AwesomeAssertions, NSubstitute, Testcontainers.

**Spec:** `docs/superpowers/specs/2026-10-10-phase-2.9-observability-design.md`. It is binding. Where the code
disagrees with it, the findings F1–F10 below give the evidence, and the rulings P1–P27 decide. Read both before any
task.

- **Repositories and branches.**

  - Part 0 changes no repository.
- **Names.** These are spec-fixed. Every task uses the constants defined in Tasks A1 and B4, never a second literal.
  - Sources and meters: `thalos.workflow` (Thalos, `WorkflowTelemetry.SourceName`) and `daedalus.manufacture`
    (Daedalus, `ManufactureTelemetry.SourceName`).
  - Spans: `thalos.workflow.dispatch`, kind `Consumer`; `thalos.workflow.host_action.{type}`;
    `thalos.workflow.store.{start|resume|cancel|fail|fail_stranded|retry}` (P10); `daedalus.manufacture.start`;
    `daedalus.manufacture.cancel`.
  - Tags: `thalos.run.id`, `thalos.node`, `thalos.seq`, `thalos.run.process`, `thalos.outcome` (`completed`, `failed`,
    `awaiting`, `skipped`), `thalos.run.state` (`Succeeded`, `Failed`, `Cancelled`), `thalos.signal`,
    `thalos.host_action`, `thalos.tool.source`, `thalos.tool`, `error.type`, `daedalus.repository`,
    `daedalus.task.id`, `daedalus.cancelled`, `gen_ai.request.model`, `daedalus.token.kind` (`input`, `output`,
    `cache_read`, `cache_write`).
  - Metrics: `thalos.workflow.runs.started`, `thalos.workflow.runs.finished`, `thalos.workflow.dispatch.duration` (ms),
    `thalos.workflow.host_action.duration` (ms), `thalos.workflow.run_tool.duration` (ms),
    `daedalus.manufacture.tokens` (`{token}`).
- **No content in telemetry.** This is the spec section "Rule for both parts". Tags carry only ids, names, counts,
  durations, outcomes and error codes. They never carry prompt or agent text, task titles or descriptions, PR titles
  or bodies, finding text, file content, credentials or token values. Span names are constants or `{type}`. A failed
  step sets Error status **without a description**, except the start span, whose description is the failure *kind*
  (P8). Every `[Trace]` in this phase sets `ExceptionDescription = false`.
- **No workarounds.** Do not hand-wrap a generated proxy to set status. Use `ErrorWhen`. Do not add a `#pragma`, a
  `[SuppressMessage]`, a `<NoWarn>` or an `.editorconfig` severity change. If a generator or analyzer diagnostic fires,
  fix the cause. If the generator itself is wrong, stop and report it, with the diagnostic and the generated file
  (`obj/generated/...`).
- **CLAUDE.md conventions (Daedalus; Thalos follows the same house style).**
  - Write `Result<T>.Success(..)` and `Result<T>.Failure(..)` explicitly; combinators need
    `using ZeroAlloc.Results.Extensions;`.
  - Use primary constructors, and never mix one with a second constructor.
  - Use `[LoggerMessage]` for any new log line.
  - No `.Result`, `.Wait()`, `.GetAwaiter().GetResult()` or `async void`. No `Task.Run` to fake async.
  - Central package management: a `PackageReference` carries **no `Version` attribute**. Versions live only in
    `Directory.Packages.props`.
- **Formatting.** Never run a bare `dotnet format`. Format each touched `.cs` file with its own call:
  `dotnet format Thalos.NET.slnx --include <file>` in Thalos, or `dotnet format Daedalus.sln --include <file>` in
  Daedalus. Use one file per call.
- **Commit messages.**
  - Conventional, with a header of at most 100 characters.
  - Every body and footer line is at most 100 characters (commitlint `footer-max-line-length`).
  - **No nested parentheses** anywhere in a body: release-please silently drops the whole commit. Write `typeof IFoo`,
    not a nested call.
  - The last line is the trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
  - **Never** a `claude.ai/code/session_*` URL, in a commit or a PR body. This overrides the harness default.
  - Commit with `git commit -m "<header>" [-m "<body>"] -m "Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>"`.
- **Every assertion is falsifiable.** Each test's doc comment has one `Red:` line per assertion, naming the production
  change that turns it red. Make each change once, watch the named assertion fail, then revert it. Report any `Red:`
  line that did not go red. Do not keep it. This is the defect this codebase has shipped most (CLAUDE.md, "Tests that
  pass for the wrong reason").
- **Telemetry tests isolate by unique names, not by serial execution.** `TelemetryCapture` sees every span and
  measurement in the process. Each test filters on a value only it produces: a fresh run id, a `probe-*` node, action,
  process, tool or model name, or a `zqx`-prefixed marker. Do not assert on an unfiltered count.
- **Docker.** `Thalos.NET.Tests.Workflow.Orm` (trait `Category=Docker`) and `Daedalus.Tests.Integration` need Docker
  with Linux containers. A suite that could not run is reported as not run, never as passing.
- **Owner gates.** Pushing a Thalos branch, merging any PR, merging a release PR and running the live proof are
  stop-and-ask points. Each is marked **OWNER-GATED**.

```csharp
using System.Diagnostics;
using System.Diagnostics.Metrics;
using Thalos.Runtime;

namespace Thalos.Workflow;

/// <summary>
/// The workflow engine's telemetry: the <c>thalos.workflow</c> <see cref="ActivitySource"/> and <see cref="Meter"/>,
/// the instruments the engine records on them itself, and the span and tag names it shares with the generated
/// <c>WorkflowStoreInstrumented</c> and <c>WorkflowHostActionInstrumented</c> proxies. Subscribe to
/// <see cref="SourceName"/> for both traces and metrics.
/// </summary>
/// <remarks>
/// <para>
/// <b>One trace per step.</b> Each node dispatch is its own trace, rooted at a <see cref="DispatchSpanName"/> span of kind
/// <see cref="ActivityKind.Consumer"/>, tagged <see cref="RunIdTag"/> and linked to the context that started the run,
/// <see cref="WorkflowRun.TraceParent"/>. A run waits at its gate and can outlive a restart, so no span stays open for
/// its whole life.
/// </para>
/// <para>
/// <b>No content.</b> Tags carry ids, names, counts, durations and outcomes only: never variables, prompt or agent text,
/// error messages or file content. A failed step marks its span with Error status and no description; the run's event
/// log keeps the error text.
/// </para>
/// </remarks>
public static class WorkflowTelemetry
{
    /// <summary>The source and meter name, <c>"thalos.workflow"</c>.</summary>
    public const string SourceName = ThalosTelemetry.WorkflowSourceName;

    /// <summary>The span each node dispatch starts.</summary>
    public const string DispatchSpanName = "thalos.workflow.dispatch";

    /// <summary>The run's id, a <see cref="Guid"/>.</summary>
    public const string RunIdTag = "thalos.run.id";

    /// <summary>The node a dispatch or host action ran.</summary>
    public const string NodeTag = "thalos.node";

    /// <summary>The run's sequence number the dispatch was for, a <see cref="long"/>.</summary>
    public const string SeqTag = "thalos.seq";

    /// <summary>The run's process name.</summary>
    public const string ProcessTag = "thalos.run.process";

    /// <summary>How a dispatch ended: <see cref="OutcomeCompleted"/>, <see cref="OutcomeFailed"/>, <see cref="OutcomeAwaiting"/> or <see cref="OutcomeSkipped"/>.</summary>
    public const string OutcomeTag = "thalos.outcome";

    /// <summary>The terminal status a finished run reached: <c>Succeeded</c>, <c>Failed</c> or <c>Cancelled</c>.</summary>
    public const string RunStateTag = "thalos.run.state";

    /// <summary>The signal a resume carried.</summary>
    public const string SignalTag = "thalos.signal";

    /// <summary>The host action's name, as a process node references it.</summary>
    public const string HostActionTag = "thalos.host_action";

    /// <summary>The full type name of an exception that escaped, as the OpenTelemetry conventions name it.</summary>
    public const string ErrorTypeTag = "error.type";

    /// <summary>The node ran and the run moved on, or reached a terminal node that succeeded.</summary>
    public const string OutcomeCompleted = "completed";

    /// <summary>The node failed, or reached a terminal node that failed.</summary>
    public const string OutcomeFailed = "failed";

    /// <summary>The node parked the run at its gate.</summary>
    public const string OutcomeAwaiting = "awaiting";

    /// <summary>The message was stale: the run was missing, past its seq, or no longer running.</summary>
    public const string OutcomeSkipped = "skipped";

    /// <summary>Counter name for started runs.</summary>
    public const string RunsStartedName = "thalos.workflow.runs.started";

    /// <summary>Counter name for runs that reached a terminal status.</summary>
    public const string RunsFinishedName = "thalos.workflow.runs.finished";

    /// <summary>Histogram name for one dispatch's duration, in milliseconds.</summary>
    public const string DispatchDurationName = "thalos.workflow.dispatch.duration";

    /// <summary>Histogram name for one host action call's duration, in milliseconds. Recorded by the generated proxy.</summary>
    public const string HostActionDurationName = "thalos.workflow.host_action.duration";

    /// <summary>The workflow engine's source.</summary>
    public static readonly ActivitySource ActivitySource = new(SourceName);

    /// <summary>Owner of the instruments below.</summary>
    public static readonly Meter Meter = new(SourceName);

    /// <summary><c>thalos.workflow.runs.started</c>, tagged <see cref="ProcessTag"/>.</summary>
    public static readonly Counter<long> RunsStarted =
        Meter.CreateCounter<long>(RunsStartedName, unit: "{run}", description: "Runs started, by process");

    /// <summary><c>thalos.workflow.runs.finished</c>, tagged <see cref="ProcessTag"/> and <see cref="RunStateTag"/>.</summary>
    public static readonly Counter<long> RunsFinished =

    /// <summary><c>thalos.workflow.dispatch.duration</c>, tagged <see cref="NodeTag"/> and <see cref="OutcomeTag"/>, or <see cref="ErrorTypeTag"/>.</summary>

        Meter.CreateHistogram<double>(DispatchDurationName, unit: "ms", description: "Duration of one node dispatch");

    /// <summary>Counts one run of <paramref name="process"/> started.</summary>
    public static void RecordRunStarted(string process) =>
        RunsStarted.Add(1, new KeyValuePair<string, object?>(ProcessTag, process));

    /// <summary>Counts one run of <paramref name="process"/> that reached the terminal <paramref name="state"/>.</summary>
    public static void RecordRunFinished(string process, WorkflowStatus state) =>
        RunsFinished.Add(
            1,
            new KeyValuePair<string, object?>(ProcessTag, process),
            new KeyValuePair<string, object?>(RunStateTag, StateName(state)));

    private static string StateName(WorkflowStatus state) => state switch
    {
        WorkflowStatus.Succeeded => nameof(WorkflowStatus.Succeeded),
        WorkflowStatus.Failed => nameof(WorkflowStatus.Failed),
        WorkflowStatus.Cancelled => nameof(WorkflowStatus.Cancelled),
        WorkflowStatus.Awaiting => nameof(WorkflowStatus.Awaiting),
        _ => nameof(WorkflowStatus.Running),
    };
}
```

```csharp
// src/Thalos.NET.Testing/TelemetryCapture.cs
using System.Collections.Concurrent;
using System.Diagnostics;
using System.Diagnostics.Metrics;

namespace Thalos.Testing;

/// <summary>
/// Captures every span and every measurement from the <see cref="ActivitySource"/>s and <see cref="Meter"/>s named at
/// construction, until disposed. For asserting on telemetry without an OpenTelemetry SDK.
/// </summary>
/// <remarks>
/// <para>
/// It listens process-wide, so it also sees what other tests running in parallel emit on the same names. Filter on
/// something only your test produces: a fresh run id, or a node, process, tool or model name no other test uses. Never
/// assert on an unfiltered count.
/// </para>
/// <para>
/// Every span from a named source is sampled with all data, so a listener-dependent code path takes the "something is
/// listening" branch while the capture lives. Measurements of type <see cref="long"/>, <see cref="int"/> and
/// <see cref="double"/> are recorded, with a copy of their tags.
/// </para>
/// </remarks>
public sealed class TelemetryCapture : IDisposable
{
    private readonly HashSet<string> _names;
    private readonly ActivityListener _activities;
    private readonly MeterListener _meters;
    private readonly ConcurrentQueue<Activity> _spans = new();
    private readonly ConcurrentQueue<CapturedMeasurement> _measurements = new();

    /// <summary>Starts capturing from the sources and meters named <paramref name="names"/>.</summary>
    /// <param name="names">Source and meter names, compared ordinally.</param>
    public TelemetryCapture(params string[] names)
    {
        ArgumentNullException.ThrowIfNull(names);
        _names = new HashSet<string>(names, StringComparer.Ordinal);

        _activities = new ActivityListener
        {
            ShouldListenTo = source => _names.Contains(source.Name),
            Sample = static (ref ActivityCreationOptions<ActivityContext> _) => ActivitySamplingResult.AllDataAndRecorded,
            ActivityStopped = _spans.Enqueue,
        };
        ActivitySource.AddActivityListener(_activities);

        _meters = new MeterListener
        {
            InstrumentPublished = (instrument, listener) =>
            {
                if (_names.Contains(instrument.Meter.Name))
                {
                    listener.EnableMeasurementEvents(instrument);
                }
            },
        };
        _meters.SetMeasurementEventCallback<long>((instrument, value, tags, _) => Record(instrument, value, tags));
        _meters.SetMeasurementEventCallback<int>((instrument, value, tags, _) => Record(instrument, value, tags));
        _meters.SetMeasurementEventCallback<double>((instrument, value, tags, _) => Record(instrument, value, tags));
        _meters.Start();
    }

    /// <summary>Every span stopped so far, in stop order.</summary>
    public IReadOnlyList<Activity> Spans => [.. _spans];

    /// <summary>Every measurement recorded so far, in record order.</summary>
    public IReadOnlyList<CapturedMeasurement> Measurements => [.. _measurements];

    /// <summary>The stopped spans whose <see cref="Activity.OperationName"/> is <paramref name="operationName"/>.</summary>
    public IReadOnlyList<Activity> SpansNamed(string operationName) =>
        [.. _spans.Where(s => string.Equals(s.OperationName, operationName, StringComparison.Ordinal))];

    /// <summary>The measurements of the instrument named <paramref name="instrument"/>.</summary>
    public IReadOnlyList<CapturedMeasurement> MeasurementsOf(string instrument) =>
        [.. _measurements.Where(m => string.Equals(m.Instrument, instrument, StringComparison.Ordinal))];

    /// <inheritdoc/>
    public void Dispose()
    {
        _activities.Dispose();
        _meters.Dispose();
    }

    private void Record(Instrument instrument, double value, ReadOnlySpan<KeyValuePair<string, object?>> tags)
    {
        var copy = new Dictionary<string, object?>(tags.Length, StringComparer.Ordinal);
        foreach (var tag in tags)
        {
            copy[tag.Key] = tag.Value;
        }

        _measurements.Enqueue(new CapturedMeasurement(instrument.Name, value, copy));
    }
}

/// <summary>One measurement a <see cref="TelemetryCapture"/> saw.</summary>
/// <param name="Instrument">The instrument's name.</param>
/// <param name="Value">The measured value, widened to <see cref="double"/>.</param>
/// <param name="Tags">A copy of the measurement's tags.</param>
public sealed record CapturedMeasurement(string Instrument, double Value, IReadOnlyDictionary<string, object?> Tags);
```

```csharp
    /// Starts this dispatch's span, or returns null when nothing listens to <see cref="WorkflowTelemetry.ActivitySource"/>.
    /// The run's start is linked, not parented: a run waits at its gate and can outlive a restart, so each step is its own
    /// trace. A run with no traceparent, or one that does not parse, is dispatched without a link.
    /// </summary>
    private static Activity? StartDispatchActivity(WorkflowDispatchMessage message, WorkflowRun? run)
    {
        var source = WorkflowTelemetry.ActivitySource;
        if (!source.HasListeners())
        {
            return null;
        }

        var links = run?.TraceParent is { } traceParent && ActivityContext.TryParse(traceParent, traceState: null, out var origin)
            ? new[] { new ActivityLink(origin) }
            : null;

        var activity = source.StartActivity(WorkflowTelemetry.DispatchSpanName, ActivityKind.Consumer, parentContext: default, tags: null, links: links);
        if (activity is null)
        {
            return null;
        }

        activity.SetTag(WorkflowTelemetry.RunIdTag, message.RunId);
        activity.SetTag(WorkflowTelemetry.NodeTag, message.Node);
        activity.SetTag(WorkflowTelemetry.SeqTag, message.Seq);
        if (run is not null)
        {
            activity.SetTag(WorkflowTelemetry.ProcessTag, run.Process);
        }

        return activity;
    }

    /// <summary>Ends a dispatch that decided its node's outcome: tags it, marks a failure, and records the duration.</summary>
    private static void EndDispatch(Activity? activity, string node, long started, DispatchOutcome outcome)
    {
        var name = OutcomeName(outcome);
        if (activity is not null)
        {
            activity.SetTag(WorkflowTelemetry.OutcomeTag, name);
            if (outcome == DispatchOutcome.Failed)
            {
                // No description: a node's error text can carry model or git output. The run's event log keeps it.
                activity.SetStatus(ActivityStatusCode.Error);
            }
        }

        WorkflowTelemetry.DispatchDuration.Record(
            Stopwatch.GetElapsedTime(started).TotalMilliseconds,
            new KeyValuePair<string, object?>(WorkflowTelemetry.NodeTag, node),
            new KeyValuePair<string, object?>(WorkflowTelemetry.OutcomeTag, name));
    }

    /// <summary>Ends a dispatch an exception escaped: no outcome was decided, so <c>error.type</c> takes its place.</summary>
    private static void EndDispatch(Activity? activity, string node, long started, Exception exception)
    {
        var errorType = exception.GetType().FullName;
        activity?.SetTag(WorkflowTelemetry.ErrorTypeTag, errorType);
        activity?.SetStatus(ActivityStatusCode.Error);

        WorkflowTelemetry.DispatchDuration.Record(
            Stopwatch.GetElapsedTime(started).TotalMilliseconds,
            new KeyValuePair<string, object?>(WorkflowTelemetry.NodeTag, node),
            new KeyValuePair<string, object?>(WorkflowTelemetry.ErrorTypeTag, errorType));
    }

    private static string OutcomeName(DispatchOutcome outcome) => outcome switch
    {
        DispatchOutcome.Completed => WorkflowTelemetry.OutcomeCompleted,
        DispatchOutcome.Failed => WorkflowTelemetry.OutcomeFailed,
        DispatchOutcome.Awaiting => WorkflowTelemetry.OutcomeAwaiting,
        _ => WorkflowTelemetry.OutcomeSkipped,
```

```csharp
// src/Thalos.NET.Mcp/RunToolDurationObserver.cs
using System.Diagnostics.Metrics;
using Thalos.Runtime;
using Thalos.Workspaces;

namespace Thalos.Mcp;

/// <summary>
/// Records <c>thalos.workflow.run_tool.duration</c> (ms), tagged <c>thalos.tool.source</c> and <c>thalos.tool</c>, for
/// every call a remote run tool source sent to a run's endpoint, sandbox <c>build</c> and <c>test</c> included. It reads
/// <see cref="RunToolCall.Elapsed"/>, which the source measured around the call. It is told only after the call
/// finished, so it records a duration and starts no span. It never reads <see cref="RunToolCall.ResultText"/>.
/// </summary>
/// <remarks>
/// The meter is named <see cref="ThalosTelemetry.WorkflowSourceName"/>, the workflow engine's. This assembly does not
/// reference the engine, so it owns its own <see cref="Meter"/> instance under that name; a listener subscribes by name.
/// </remarks>
internal sealed class RunToolDurationObserver : IRunToolCallObserver
{
    internal const string InstrumentName = "thalos.workflow.run_tool.duration";

    internal const string SourceTag = "thalos.tool.source";

    internal const string ToolTag = "thalos.tool";

    private static readonly Meter Meter = new(ThalosTelemetry.WorkflowSourceName);

    private static readonly Histogram<double> Duration =
        Meter.CreateHistogram<double>(InstrumentName, unit: "ms", description: "Duration of one run tool call");

    /// <inheritdoc/>
    public ValueTask OnCompletedAsync(RunToolCall completed, CancellationToken ct)
    {
        ArgumentNullException.ThrowIfNull(completed);
        Duration.Record(
            completed.Elapsed.TotalMilliseconds,
            new KeyValuePair<string, object?>(SourceTag, completed.Source),
            new KeyValuePair<string, object?>(ToolTag, completed.Tool));
        return ValueTask.CompletedTask;
    }
}
```

```csharp
// tests/Daedalus.Tests.Integration/Workflow/TelemetryEndToEndTests.cs
using System.Diagnostics;
using Daedalus.Agents.Workflow;
using Daedalus.Api.Controllers;
using Daedalus.Domain.Entities;
using Daedalus.Infrastructure.Persistence;
using Daedalus.Tests.Integration.Fixtures;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.DependencyInjection;
using Microsoft.Extensions.DependencyInjection.Extensions;
using OpenTelemetry.Trace;
using Thalos;
using Thalos.Git;
using Thalos.Testing;
using Thalos.Workflow;
using DomainTask = Daedalus.Domain.Entities.Task;
using Task = System.Threading.Tasks.Task;

namespace Daedalus.Tests.Integration.Workflow;

/// <summary>
///     Phase 2.9 spec, Tests, "Privacy, end to end" and the wiring. A board task runs the real manufacture process to the
///     gate, is approved, publishes and succeeds. Only the model and the pull-request host are replaced. Every span is
///     captured. The run must show one trace per step, linked back to its start, with the host actions, the approval
///     and the token spend visible. No span may carry the task's text, the agent's text or the PR's text.
/// </summary>
[Collection(DatabaseCollection.Name)]
public sealed class TelemetryEndToEndTests(PostgresFixture fixture)
{
    private static readonly string[] Sources =
        ["thalos", WorkflowTelemetry.SourceName, "ZeroAlloc.Mediator", ManufactureTelemetry.SourceName, "Microsoft.AspNetCore", "System.Net.Http"];

    private static readonly string[] Steps = ["implement", "review", "retrospect", "gate", "publish", "file-findings", "done"];

    /// <summary>
    ///     Red: drop the starter proxy from the enabled registration; no start span exists.
    ///     Red: delete the task-id SetTag; no request span carries the task id.
    ///     Red: drop the dispatch span; the step list is empty.
    ///     Red: parent each dispatch on the stored context instead of linking it; the trace-id assertion fails.
    ///     Red: drop the links argument; the link assertion fails.
    ///     Red: drop the host-action wrapping in the dispatcher; the publish host-action span is missing.
    ///     Red: drop the store proxy from AddWorkflowOrm; the resume span is missing.
    ///     Red: make ReviewHandoffWorkflowStore call RecordAsync; the token measurements are missing.
    ///     Red: drop thalos.workflow from TracedSources; the OpenTelemetry exporter has no dispatch span.
    ///     Red: drop the ASP.NET Core Filter; the exporter has a /health span.
    ///     Red: add [TraceTag("daedalus.work_intent", "WorkIntent")] to IManufactureRunStarter.StartAsync; the content
    ///     assertion names the start span.
    /// </summary>
    [Fact]
    public async Task A_manufacture_run_is_traced_step_by_step_and_no_span_carries_its_content()
    {
        var marker = $"zqx{Guid.NewGuid():N}"[..13];
        var title = $"Probe title {marker}";
        var description = $"Probe description {marker}: filter cancelled tasks out of the claim query";
        var model = $"probe-model-{marker}";
        var pullRequests = new FakePullRequestPublisher();
        var exported = new List<Activity>();
        using var capture = new TelemetryCapture(Sources);

        await using var host = await ScratchWorkflowHost.StartAsync(
            fixture,
            new ScriptedManufactureRuntime(new TurnUsage(1_200, 80, model) { CacheReadTokens = 900, CacheWriteTokens = 150 }),
            seed: [("README.md", "usage"), ("AGENT.md", "Run dotnet test.\n")],
            configureServices: services =>
            {
                services.RemoveAll<WorkflowOutboxDispatchOptions>();
                services.AddSingleton(new WorkflowOutboxDispatchOptions { PollingInterval = TimeSpan.FromMilliseconds(250) });
                services.RemoveAll<IPullRequestPublisher>();
                services.RemoveAll<IOpenPullRequestLookup>();
                services.AddSingleton<IPullRequestPublisher>(pullRequests);
                services.AddSingleton<IOpenPullRequestLookup>(pullRequests);
                services.ConfigureOpenTelemetryTracerProvider(tracing => tracing.AddInMemoryExporter(exported));
            });

        var project = Project.Create(Guid.NewGuid(), "Sandbox", "The scratch remote", repositoryUrl: host.Remote.Url).Value;
        var task = DomainTask.Create(Guid.NewGuid(), project.Id, "TASK-TEL", title, description, Priority.Medium, "Testing", 1, Complexity.Medium, "Implement it.").Value;
        project.AddTask(task).IsSuccess.Should().BeTrue();
        await using (var db = await host.Factory.Services.GetRequiredService<IDbContextFactory<ApplicationDbContext>>().CreateDbContextAsync())
        {
            db.Projects.Add(project);
            await db.SaveChangesAsync();
        }

        using var client = host.Client("a-developer", "developer");
        var start = await client.PostAsync($"/api/tasks/{task.Id}/manufacture", content: null);
        start.StatusCode.Should().Be(HttpStatusCode.Created);
        var runId = (await start.Content.ReadFromJsonAsync<StartWorkflowRunResponse>())!.RunId;
        await host.WaitForAsync(runId, r => r.Status == WorkflowStatus.Awaiting, "parked at the gate");
        var resume = await client.PostAsJsonAsync(
            $"/api/workflow-runs/{runId}/resume", new { signal = "human_approval", payload = (string?)null, applyStandingInstructions = true });
        resume.StatusCode.Should().Be(HttpStatusCode.NoContent);
        await host.WaitForAsync(runId, r => r.Status == WorkflowStatus.Succeeded, "succeeded");
        (await client.GetAsync("/health")).IsSuccessStatusCode.Should().BeTrue();

        var spans = capture.Spans;
        bool OfRun(Activity span) => Equals(span.GetTagItem(WorkflowTelemetry.RunIdTag), runId);

        // The start, and the request that made it.
        var startSpan = spans.Should().ContainSingle(s => s.OperationName == ManufactureTelemetry.StartSpanName && OfRun(s)).Subject;
        startSpan.GetTagItem(ManufactureTelemetry.RepositoryTag).Should().Be(ScratchWorkflowHost.Repository);
        spans.Should().Contain(s => s.Source.Name == "Microsoft.AspNetCore"
            && Equals(s.GetTagItem(ManufactureTelemetry.TaskIdTag), task.Id) && s.TraceId == startSpan.TraceId);

        // One trace per step, each linked back into the start's trace.
        var dispatches = spans.Where(s => s.OperationName == WorkflowTelemetry.DispatchSpanName && OfRun(s)).ToList();
        dispatches.Select(d => (string?)d.GetTagItem(WorkflowTelemetry.NodeTag)).Should().BeEquivalentTo(Steps);
        dispatches.Should().OnlyContain(d => d.TraceId != startSpan.TraceId && d.Links.Any(l => l.Context.TraceId == startSpan.TraceId));
        dispatches.Select(d => d.TraceId).Should().OnlyHaveUniqueItems();
        dispatches.Single(d => Equals(d.GetTagItem(WorkflowTelemetry.NodeTag), "gate")).GetTagItem(WorkflowTelemetry.OutcomeTag).Should().Be(WorkflowTelemetry.OutcomeAwaiting);

        // The host action nests in its step; the approval is a resume span with its signal.
        var publish = dispatches.Single(d => Equals(d.GetTagItem(WorkflowTelemetry.NodeTag), "publish"));
        spans.Should().Contain(s => s.OperationName == "thalos.workflow.host_action.OpenPullRequestAction" && OfRun(s) && s.TraceId == publish.TraceId);
        spans.Should().Contain(s => s.OperationName == "thalos.workflow.store.resume" && OfRun(s) && Equals(s.GetTagItem(WorkflowTelemetry.SignalTag), "human_approval"));

        // The token spend, from the live completion.
        capture.MeasurementsOf(ManufactureTelemetry.TokensMetricName)
            .Where(m => Equals(m.Tags.GetValueOrDefault(ManufactureTelemetry.ModelTag), model))
            .Select(m => (Kind: m.Tags[ManufactureTelemetry.TokenKindTag], m.Value))
            .Should().BeEquivalentTo(new (object?, double)[] { ("input", 1_200), ("output", 80), ("cache_read", 900), ("cache_write", 150) });

        // The real host's OpenTelemetry pipeline exports the workflow spans, and not the health probe.
        exported.Should().Contain(a => a.OperationName == WorkflowTelemetry.DispatchSpanName && OfRun(a));
        exported.Should().NotContain(a => a.Source.Name == "Microsoft.AspNetCore" && Equals(a.GetTagItem("url.path"), "/health"));

        // No content anywhere: not in a tag, a span name or a status description.
        pullRequests.LastBody.Should().NotBeNullOrEmpty();
        string[] forbidden =
        [
            marker, title, description, "filtered cancelled tasks", "the claim query ignored status",
            ScriptedManufactureRuntime.LearnedLine, pullRequests.LastBody!, pullRequests.LastTitle!,
        ];
        foreach (var span in spans)
        {
            var texts = span.TagObjects.Select(t => t.Value?.ToString()).Append(span.DisplayName).Append(span.StatusDescription);
            texts.Should().NotContain(
                text => text != null && forbidden.Any(f => text.Contains(f, StringComparison.Ordinal)),
                $"span '{span.OperationName}' from '{span.Source.Name}' must carry no content");
        }
    }
}
```
