### Rulings

Ruling PF-1: `VerdictBadge` and every `RunVerdict` switch must carry a discard arm that
renders `Unknown` as a muted badge reading "Unknown". The enum has nine members because
`Unknown = 0` is a deliberate sentinel — STATE.md open decision 1 records that
`AgentErrorCode` making a real value member 0 produced false-passing tests three times on
one branch. Keeping the sentinel is right; leaving the render path non-exhaustive is not.
A C# switch expression with no discard throws at runtime on an unmatched value, and inside
a Blazor render that is a blank page — on the one page whose stated job is to never blank.
Cost if wrong: one extra unreachable badge variant.

Ruling PF-2: Task 3 step 3's shell block is under-specified for this machine. The container
is `daedalus_postgres` and credentials are `daedalus`/`daedalus` per STATE.md, not the
`postgres`/`postgres` the code defaults to. `-o /tmp/mig.sql` must be a Windows-style path —
phase 1.5 lost time to POSIX git-bash paths handed to Windows processes. Both resolved in
the dispatch rather than left to the implementer. Cost if wrong: one failed command and a retry.

Ruling PF-3: Task 3's `dotnet ef migrations add` uses `--startup-project src/Daedalus.Api`,
which cannot boot (Task 1's blocker). This is NOT a conflict: EF uses the design-time
factory and never builds the host, which is why phase 1.5 added two migrations against the
same broken host. Task 3 does not depend on Task 1 succeeding. Cost if wrong: Task 3 reports
BLOCKED and moves behind Task 1.

Task 6: Ruling T6-C: the overview must diagnose the NEXT occurrence, not only the latest execution.
  Found by the reviewer, and it is a defect in MY plan text, not the implementation — my Classify

  reports Delivered, today's digest never fired and the page says healthy. That is death-cause 2 for
  the common case and it defeats the page's purpose.

  occurrence means the machinery is not running NOW, which outranks what happened last time; the
  run-history drill-down still surfaces the past failure. Cost if wrong: a schedule shows Overdue
