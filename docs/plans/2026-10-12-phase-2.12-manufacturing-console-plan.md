# Phase 2.12: The Manufacturing Console, Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An operator follows a manufacture run live in the browser, from Manufacture on a board task to its pull
request, and approves or cancels it at the human gate without touching the REST API.

**Architecture:** Three repositories, in order.

- **Part A0, ZeroAlloc.Flux 1.1.11.** `ZeroAlloc.Flux.Blazor` stops taking a framework reference on the ASP.NET Core
  shared framework, which no browser-wasm runtime pack exists for, and references `Microsoft.AspNetCore.Components`
  instead. A Blazor WebAssembly smoke sample in its CI proves it builds. The README stops promising effects and store
  auto-wiring that 1.1.10 does not ship.
- **Part A, Thalos.NET 0.16.0.** `IWorkflowRunQuery` lists run summaries newest first with keyset paging and never the
  run's variables. `IWorkflowRunObserver` is called by `OrmWorkflowStore` after every committed change and never for a
  refused one; a throwing observer is logged by exception type and swallowed.
- **Part B, Daedalus.** The run DTOs move to `Daedalus.Application/DTOs/WorkflowRuns`, so the API and the Web bind one
  shape. The run view gains `Steps[]` and `Checked[]`. `GET /api/workflow-runs` lists runs with their board task. A
  SignalR hub broadcasts a content-free `WorkflowRunChanged`, fed by an observer through a bounded channel. The Web
  holds runs and tasks in ZeroAlloc.Flux features; effects are plain services that dispatch actions; a hub connection
  turns each `WorkflowRunChanged` into a re-fetch. The pages are `/runs` and `/runs/{id}`, and `/tasks` moves onto
  Flux.

**Tech Stack:** .NET 10 / C# 13. ZeroAlloc.Flux and ZeroAlloc.Flux.Blazor 1.1.11 (Part A0), Thalos.NET 0.16.0 (Part
A), ASP.NET Core SignalR (server in the shared framework; client `Microsoft.AspNetCore.SignalR.Client` 10.0.12),
System.Text.Json source generation, Radzen.Blazor 8.7.5, ZeroAlloc.Results 1.4.0, EF Core 10 for the task index,
Npgsql for Thalos's store. Tests: xUnit, AwesomeAssertions, NSubstitute, Testcontainers PostgreSQL,
`Thalos.Testing.TelemetryCapture`, the OpenTelemetry in-memory exporter, Microsoft.Playwright with NUnit for the
browser suite, bunit 2.11.3 in Flux's own tests.

**Spec:** `docs/superpowers/specs/2026-10-12-phase-2.12-manufacturing-console-design.md`, decisions D1 to D7. **UI
contract:** `docs/plans/2026-10-12-phase-2.12-manufacturing-console-ui-contract.md`. Both are binding. Where the code or
a package disagrees with them, the findings F1 to F14 give the evidence and the rulings P1 to P30 decide. Read the
spec, the contract, the findings and the rulings before any task.

## Global Constraints

- **Repositories and branches.**
  - Part A0: `C:\Projects\Prive\ZeroAlloc\ZeroAlloc.Flux`, a new branch `fix/blazor-wasm` from `origin/main` (the local
    checkout is on an old branch; never reuse it).
  - Part A: `C:\Projects\Prive\Thalos.NET`, a new branch `feat/workflow-run-console` from `origin/main` (local `main` is
    stale and the checkout is on `feat/workflow-telemetry`; never reuse either).
  - Part B: `C:\Projects\Prive\daedalus`, branch `feat/phase-2.12-manufacturing-console`, which carries the spec, the
    contract and this plan. `Daedalus.sln`. Part B is one PR.
  - Never push, open or merge a PR, or release, without the owner: every such step is **OWNER-GATED**.
- **Order.** Part A0 and Part A are implemented first. Part B starts only after ZeroAlloc.Flux 1.1.11 and Thalos.NET
  0.16.0 are on nuget.org (Tasks A0.2 and A3).
- **Packages (Part B).** All eighteen `Thalos.NET.*` at `0.16.0`. `ZeroAlloc.Flux` and `ZeroAlloc.Flux.Blazor`
  `1.1.11`. `Microsoft.AspNetCore.SignalR.Client` `10.0.12`. No `Fluxor`, no `bunit` in Daedalus, no
  `Microsoft.AspNetCore.SignalR.StackExchangeRedis`, no raw `Polly`.
- **Central package management (Daedalus and Thalos).** A `PackageReference` carries no `Version`; versions live only in
  `Directory.Packages.props`, and each new or raised pin carries a comment naming why. ZeroAlloc.Flux has no central
  package management: versions there are inline, as its csproj files already do.
- **No task content and no token in telemetry or logs.** `WorkflowRunChanged` carries exactly `Id`, `Status`,
  `CurrentNode` and `AwaitingSignal`. `WorkflowRunSummary` and the list endpoint carry no variables and no last error.
  No span, metric or log record ever carries an `access_token` value. An observer failure is logged by exception type
  name only, never `ex.Message`, `ex.ToString()` or the exception object.
- **Writes stay where they are.** The console only calls the existing `resume`, `cancel` and `retry` endpoints; it adds
  no write path.
- **No workarounds.** No `#pragma`, `[SuppressMessage]`, `<NoWarn>` or `.editorconfig` severity change. If an analyzer
  fires, fix the code. If a generator or package is wrong, stop and report it with the diagnostic.
- **Build before testing.** Analyzer warnings are errors in all three repositories. Build each task's production project
  before its tests.
- **CLAUDE.md conventions (Daedalus).**
  - `Result<T>.Success(..)` and `Result<T>.Failure(..)` explicitly; with `T` = `string` never a bare return.
  - Primary constructors for DI, never mixed with a second constructor in one class.
  - `[LoggerMessage]` for every new log line, in all three repositories.
  - No `.Result`, `.Wait()`, `.GetAwaiter().GetResult()`, `async void` outside event handlers, or `Task.Run` to fake
    async.
  - `AsNoTracking()` for read-only EF queries.
- **Design system.** `docs/design/MASTER.md`: Radzen only, `--rz-*` tokens only, no hex literal in a component, status
  as badge text plus severity, `RadzenText` with `TextStyle`, no new gradient, no webfont, no icon beside a heading.
- **Every assertion is falsifiable.** Each test's doc comment has one `Red:` line per assertion naming the production
  change that turns it red. Make each change once, watch that assertion fail, revert it. Report every `Red:` line that
  did not go red, and do not keep it.
- **Line numbers are hints.** Locate every edit by the quoted code.
- **Line endings.** Daedalus files are CRLF; Thalos and ZeroAlloc files are LF (`.editorconfig`). Edit with the Edit
  tool. Never `sed -i` a tracked file.
- **One `dotnet test` process at a time** per repository; they share `obj/` and Docker.
- **Formatting.** Daedalus: never a bare `dotnet format`; before each commit run
  `dotnet format Daedalus.sln --verify-no-changes --include <file>` per touched `.cs` file, and without
  `--verify-no-changes` for a file it reports. Thalos and Flux: `dotnet format <slnx> --verify-no-changes --include
  <file>` the same way.
- **Commit messages.**
  - Conventional: `feat`, `fix`, `refactor`, `test`, `docs`, `build`, `ci`, `chore`; header at most 100 characters;
    ZeroAlloc subjects start lowercase. `fix:` only for a defect that shipped; a correction to this branch's own work
    is `refactor:`, `test:` or `docs:`.
  - Every body and footer line at most 100 characters.
  - **No nested parentheses** anywhere in a body: release-please silently drops the commit. Write `typeof IFoo`.
  - The last line is `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Never a `Claude-Session:` line or a
    `claude.ai` URL.
  - Commit with `git commit -m "<header>" -m "<body>" -m "Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>"`.
- **Docker.** The Thalos Orm tests, Daedalus Integration and both Playwright suites need Docker with Linux containers.
  A suite that could not run is reported as not run, never as passing.
- **Owner gates.** Every push, PR, merge, release and the live proof is marked **OWNER-GATED**: stop and ask.

```csharp
namespace Thalos.Workflow;

/// <summary>
///     Lists workflow runs for an operator console: newest first by creation time, then by id, one keyset page at a
///     time. A summary never carries the run's variables or its last error, so no work content can leave through a
///     listing.
/// </summary>
public interface IWorkflowRunQuery
{
    /// <summary>One page of the runs that match <paramref name="filter"/>.</summary>
    /// <exception cref="ArgumentOutOfRangeException"><see cref="WorkflowRunFilter.Take"/> is outside 1 to <see cref="WorkflowRunFilter.MaxTake"/>.</exception>
    ValueTask<WorkflowRunPage> ListAsync(WorkflowRunFilter filter, CancellationToken ct);
}

/// <summary>What <see cref="IWorkflowRunQuery.ListAsync"/> returns.</summary>
public sealed record WorkflowRunFilter
{
    /// <summary>The largest page <see cref="IWorkflowRunQuery.ListAsync"/> returns.</summary>
    public const int MaxTake = 100;

    /// <summary>Only runs in this status, or every status when <see langword="null"/>.</summary>
    public WorkflowStatus? Status { get; init; }

    /// <summary>Only runs of this process, compared exactly, or every process when <see langword="null"/>.</summary>
    public string? Process { get; init; }

    /// <summary>Only runs strictly older than this cursor, or from the newest run when <see langword="null"/>.</summary>
    public WorkflowRunCursor? After { get; init; }

    /// <summary>How many runs to return at most, 1 to <see cref="MaxTake"/>.</summary>
    public int Take { get; init; } = 25;
}

/// <summary>A position in the newest-first order: the creation time and id of the last run a page returned.</summary>
/// <param name="CreatedAt">The run's creation time, as the store recorded it.</param>
/// <param name="Id">The run's id, which breaks ties between runs created in the same instant.</param>
public sealed record WorkflowRunCursor(DateTimeOffset CreatedAt, Guid Id);

/// <summary>One page of runs.</summary>
/// <param name="Runs">The runs, newest first.</param>
/// <param name="Next">The cursor for the next page, or <see langword="null"/> when no older run matches.</param>
public sealed record WorkflowRunPage(IReadOnlyList<WorkflowRunSummary> Runs, WorkflowRunCursor? Next);

/// <summary>What a console shows about one run without opening it.</summary>
public sealed record WorkflowRunSummary
{
    /// <summary>The run's identity.</summary>
    public required Guid Id { get; init; }

    /// <summary>The process the run executes.</summary>
    public required string Process { get; init; }

    /// <summary>The version of that process.</summary>
    public required int ProcessVersion { get; init; }

    /// <summary>The run's lifecycle status.</summary>
    public required WorkflowStatus Status { get; init; }

    /// <summary>The node the run is positioned at.</summary>
    public required string CurrentNode { get; init; }

    /// <summary>The signal a parked run waits on, or <see langword="null"/>.</summary>
    public string? AwaitingSignal { get; init; }

    /// <summary>Who started the run, or <see langword="null"/> for a run started before 0.11.0.</summary>
    public RunPrincipal? StartedBy { get; init; }

    /// <summary>When the run was created, on the store's clock.</summary>
    public required DateTimeOffset CreatedAt { get; init; }

    /// <summary>When the run last changed, on the store's clock.</summary>
    public required DateTimeOffset UpdatedAt { get; init; }
}
```

```csharp
namespace Thalos.Workflow;

/// <summary>
///     Told about every change the workflow store commits to a run, after the commit, and never about a change the
///     store refused. Use it to notify a console; never to change the run, and never to block: the store awaits each
///     observer in turn on the caller's path. An observer that throws is logged by exception type and ignored, because
///     the change is already committed.
/// </summary>
public interface IWorkflowRunObserver
{
    /// <summary>Called once per committed change.</summary>
    ValueTask OnChangedAsync(WorkflowRunChange change, CancellationToken ct);
}

/// <summary>What changed. Carries no variables, outcome, error or payload, so it can be broadcast as it is.</summary>
/// <param name="RunId">The run that changed.</param>
/// <param name="Kind">Which store operation committed the change.</param>
/// <param name="Status">The run's status after the change.</param>
/// <param name="CurrentNode">The node the run is at after the change.</param>
/// <param name="AwaitingSignal">The signal the run waits on after the change, or <see langword="null"/>.</param>
public sealed record WorkflowRunChange(
    Guid RunId, WorkflowRunChangeKind Kind, WorkflowStatus Status, string CurrentNode, string? AwaitingSignal);

/// <summary>The store operation that committed a <see cref="WorkflowRunChange"/>.</summary>
public enum WorkflowRunChangeKind
{
    /// <summary><see cref="IWorkflowStore.StartAsync"/> created the run.</summary>
    Started,

    /// <summary><see cref="IWorkflowStore.CompleteNodeAsync"/> moved the run on.</summary>
    NodeCompleted,

    /// <summary><see cref="IWorkflowStore.ResumeAsync"/> moved a parked run on.</summary>
    Resumed,

    /// <summary><see cref="IWorkflowStore.FailAsync"/> or <see cref="IWorkflowStore.FailStrandedAsync"/> failed the run.</summary>
    Failed,

    /// <summary><see cref="IWorkflowStore.CancelAsync"/> cancelled the run.</summary>
    Cancelled,

    /// <summary><see cref="IWorkflowStore.RetryFailedNodeAsync"/> re-queued a failed node.</summary>

}
```

`src/Daedalus.Api/Controllers/WorkflowRunCursorCodec.cs`:

```csharp
using System.Buffers.Binary;
using System.Buffers.Text;
using Thalos.Workflow;

namespace Daedalus.Api.Controllers;

/// <summary>
///     The list's <c>after</c> cursor on the wire: base64url of the run's creation time in UTC ticks, 8 bytes big
///     endian, then its id, 16 bytes. Opaque to clients; only this class reads or writes it.
/// </summary>
internal static class WorkflowRunCursorCodec
{
    private const int Length = 24;

    public static string Encode(WorkflowRunCursor cursor)
    {
        Span<byte> bytes = stackalloc byte[Length];
        BinaryPrimitives.WriteInt64BigEndian(bytes, cursor.CreatedAt.UtcTicks);
        cursor.Id.TryWriteBytes(bytes[8..]);
        return Base64Url.EncodeToString(bytes);
    }

    public static bool TryDecode(string text, out WorkflowRunCursor cursor)
    {
        cursor = null!;
        Span<byte> bytes = stackalloc byte[Length];
        if (string.IsNullOrEmpty(text) || !Base64Url.TryDecodeFromChars(text, bytes, out var written) || written != Length)
        {
            return false;
        }

        cursor = new WorkflowRunCursor(
            new DateTimeOffset(BinaryPrimitives.ReadInt64BigEndian(bytes), TimeSpan.Zero), new Guid(bytes[8..]));
        return true;
    }
}
```

`Base64Url.TryDecodeFromChars` returns `false` when the destination is too small, which is how a longer input is
refused; a shorter one gives `written != Length`.

```csharp
using System.Diagnostics;
using OpenTelemetry;

namespace Daedalus.ServiceDefaults;

/// <summary>
///     Redacts the value of any <c>access_token</c> query parameter on ASP.NET Core server spans before export. The
///     console's hub connection carries its bearer token there, because a browser cannot set headers on a WebSocket,
///     and the instrumentation exports <c>url.query</c> with only a fixed list of keys redacted.
/// </summary>
internal sealed class ServerQueryRedactionProcessor : BaseProcessor<Activity>
{
    internal const string AspNetCoreSource = "Microsoft.AspNetCore";
    private const string QueryTag = "url.query";
    private const string TokenName = "access_token";

    public override void OnEnd(Activity data)
    {
        if (data.Source.Name == AspNetCoreSource && data.GetTagItem(QueryTag) is string query && Redact(query) is { } redacted)
        {
            data.SetTag(QueryTag, redacted);
        }
    }

    /// <summary>The query with every <c>access_token</c> value replaced by <c>Redacted</c>, or <see langword="null"/> when it has none.</summary>
    internal static string? Redact(string query)
    {
        var prefix = query.StartsWith('?') ? "?" : string.Empty;
        var pairs = query[prefix.Length..].Split('&');
        var changed = false;
        for (var i = 0; i < pairs.Length; i++)
        {
            var name = pairs[i].Split('=', 2)[0];
            if (string.Equals(name, TokenName, StringComparison.OrdinalIgnoreCase))
            {
                pairs[i] = name + "=Redacted";
                changed = true;
            }
        }

        return changed ? prefix + string.Join('&', pairs) : null;
    }
}
```

```csharp
    IHubContext<WorkflowRunsHub> hub, ILogger<WorkflowRunChangeBroadcaster> logger) : BackgroundService, IWorkflowRunObserver
{
    private readonly Channel<WorkflowRunChanged> _changes = Channel.CreateBounded<WorkflowRunChanged>(
        new BoundedChannelOptions(256) { FullMode = BoundedChannelFullMode.DropOldest, SingleReader = true });

    /// <inheritdoc/>
    public ValueTask OnChangedAsync(WorkflowRunChange change, CancellationToken ct)
    {
        _changes.Writer.TryWrite(new WorkflowRunChanged(change.RunId, change.Status.ToString(), change.CurrentNode, change.AwaitingSignal));
        return ValueTask.CompletedTask;
    }

    /// <inheritdoc/>
    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        await foreach (var message in _changes.Reader.ReadAllAsync(stoppingToken).ConfigureAwait(false))
        {
            try
            {
                await hub.Clients.All.SendAsync(WorkflowRunsHub.RunChangedMethod, message, stoppingToken).ConfigureAwait(false);
            }
            catch (Exception exception) when (exception is not OperationCanceledException)
            {
                LogSendFailed(logger, message.Id, exception.GetType().FullName ?? exception.GetType().Name);
            }
        }
    }

    [LoggerMessage(Level = LogLevel.Warning,
        Message = "Sending the change of run {RunId} to the console failed with {ExceptionType}. Clients re-fetch on the next change.")]
    private static partial void LogSendFailed(ILogger logger, Guid runId, string exceptionType);
}
```

```csharp
using Daedalus.Application.DTOs.WorkflowRuns;
using ZeroAlloc.Flux;

namespace Daedalus.Web.State.Runs;

/// <summary>
///     The runs feature's I/O. Each method dispatches what it starts and what it got; an expected failure is an
///     action, never an exception. Cancellation propagates.
/// </summary>
public sealed class RunsEffects(ApiClient api, IDispatcher dispatcher, IStore<RunsState> runs)
{
    public async Task LoadListAsync(RunListQuery query, CancellationToken ct)
    {
        await dispatcher.DispatchAsync(new RunListRequested(query));
        var result = await api.GetRunsAsync(query, ct);
        await (result.IsSuccess
            ? dispatcher.DispatchAsync(new RunListLoaded(query, result.Value))
            : dispatcher.DispatchAsync(new RunListFailed(query, result.Error)));
    }

    public async Task LoadRunAsync(Guid id, CancellationToken ct)
    {
        await dispatcher.DispatchAsync(new RunSelected(id));
        await dispatcher.DispatchAsync(new RunLoadStarted(id));
        var result = await api.GetRunAsync(id, ct);
        if (result.IsFailure)
        {
            await dispatcher.DispatchAsync(new RunLoadFailed(id, result.Error));
        }
        else if (result.Value is { } run)
        {
            await dispatcher.DispatchAsync(new RunLoaded(run));
        }
        else
        {
            await dispatcher.DispatchAsync(new RunNotFound(id));
        }
    }

    public async Task LoadAwaitingApprovalAsync(CancellationToken ct)
    {
        var result = await api.GetRunsAsync(new RunListQuery("Awaiting", null, null, Take: 100), ct);
        if (result.IsSuccess)
        {
            var count = result.Value.Runs.Count(r => r.AwaitingSignal == RunSignals.HumanApproval);
            await dispatcher.DispatchAsync(new AwaitingApprovalLoaded(count, result.Value.Next is not null));
        }
    }

    public async Task<Result> ApproveAsync(CancellationToken ct)
    {
        var state = runs.Value;
        if (state.SelectedId is not { } id)
        {
            return Result.Failure("No run is open.");
        }

        await dispatcher.DispatchAsync(new GateSubmitStarted());
        var result = await api.ApproveRunAsync(id, [.. state.Gate.Dropped], state.Gate.ApplyStandingInstructions, ct);
        if (result.IsSuccess)
        {
            await dispatcher.DispatchAsync(new GateSubmitSucceeded());
        }
        else
        {
            await dispatcher.DispatchAsync(new GateSubmitFailed(result.Error));
            await LoadRunAsync(id, ct);
        }

        return result;
    }

    public async Task<Result> CancelAsync(Guid id, string? reason, CancellationToken ct)
    {
        var result = await api.CancelRunAsync(id, reason, ct);
        if (result.IsFailure)
        {
            await LoadRunAsync(id, ct);
        }

        return result;
    }

    public async Task<Result> RetryAsync(Guid id, CancellationToken ct)
    {
        var result = await api.RetryRunAsync(id, ct);
        if (result.IsFailure)
        {
            await LoadRunAsync(id, ct);
        }

        return result;
    }

    public async Task OnRunChangedAsync(WorkflowRunChanged change, CancellationToken ct)
    {
        var state = runs.Value;
        if (state.SelectedId == change.Id)
        {
            await LoadRunAsync(change.Id, ct);
        }

        if (state.List is not null && (state.Query.After is null || state.List.Runs.Any(r => r.Id == change.Id)))
        {
            await LoadListAsync(state.Query, ct);
        }

        await LoadAwaitingApprovalAsync(ct);
    }

    public async Task RefreshAllAsync(CancellationToken ct)
    {
        var state = runs.Value;
        if (state.SelectedId is { } id)
        {
            await LoadRunAsync(id, ct);
        }

        if (state.List is not null)
        {
            await LoadListAsync(state.Query, ct);
        }

        await LoadAwaitingApprovalAsync(ct);
    }
}
```

```csharp
using System.Security.Claims;
using System.Text.Json;
using Microsoft.AspNetCore.Components.WebAssembly.Authentication;
using Microsoft.AspNetCore.Components.WebAssembly.Authentication.Internal;

namespace Daedalus.Web.Auth;

/// <summary>
///     Keycloak sends realm roles as one JSON array claim named <c>roles</c>; Blazor would keep it as one string, so
///     <c>IsInRole</c> never matched. This splits it into one role claim per role.
/// </summary>
public sealed class RolesClaimsPrincipalFactory(IAccessTokenProviderAccessor accessor)
    : AccountClaimsPrincipalFactory<RemoteUserAccount>(accessor)
{
    private const string RolesClaim = "roles";

    public override async ValueTask<ClaimsPrincipal> CreateUserAsync(RemoteUserAccount account, RemoteAuthenticationUserOptions options)
    {
        var user = await base.CreateUserAsync(account, options);
        if (user.Identity is not ClaimsIdentity { IsAuthenticated: true } identity
            || !account.AdditionalProperties.TryGetValue(RolesClaim, out var raw)
            || raw is not JsonElement { ValueKind: JsonValueKind.Array } roles)
        {
            return user;
        }

        foreach (var claim in identity.FindAll(RolesClaim).ToList())
        {
            identity.RemoveClaim(claim);
        }

        foreach (var role in roles.EnumerateArray())
        {
            if (role.GetString() is { Length: > 0 } name)
            {
                identity.AddClaim(new Claim(options.RoleClaim ?? ClaimTypes.Role, name));
            }
        }

        return user;
    }
}
```

```csharp
using Daedalus.Application.DTOs.WorkflowRuns;
using Daedalus.Web.Auth;
using Daedalus.Web.State.Runs;
using Daedalus.Web.State.Tasks;
using Microsoft.AspNetCore.Components.Authorization;
using Microsoft.AspNetCore.Components.WebAssembly.Authentication;
using Microsoft.AspNetCore.Http.Connections;
using Microsoft.AspNetCore.SignalR.Client;
using Microsoft.Extensions.DependencyInjection;
using ZeroAlloc.Flux;

namespace Daedalus.Web.State;

/// <summary>
///     The console's one live connection. Opened once per app for a user who may view runs; every
///     <c>RunChanged</c> becomes a re-fetch, and a reconnect re-fetches everything on screen, because messages sent
///     while disconnected are lost.
/// </summary>
public sealed class RunHubConnection(
    ApiBaseAddress api,
    AuthenticationStateProvider authentication,
    IServiceProvider services,
    IDispatcher dispatcher,
    RunsEffects runs,
    TasksEffects tasks) : IAsyncDisposable
{
    private const string Path = "hubs/workflow-runs";
    private const string RunChangedMethod = "RunChanged";
    private readonly SemaphoreSlim _gate = new(1, 1);
    private HubConnection? _connection;

    public async Task EnsureStartedAsync(CancellationToken ct)
    {
        await _gate.WaitAsync(ct);
        try
        {
            if (_connection is not null)
            {
                return;
            }

            var user = (await authentication.GetAuthenticationStateAsync()).User;
            if (!RunAccess.CanView(user))
            {
                return;
            }

            _connection = Build();
            _connection.On<WorkflowRunChanged>(RunChangedMethod, change => OnChangedAsync(change));
            _connection.Reconnecting += _ => dispatcher.DispatchAsync(new HubStatusChanged(HubStatus.Reconnecting)).AsTask();
            _connection.Reconnected += async _ =>
            {
                await dispatcher.DispatchAsync(new HubStatusChanged(HubStatus.Connected));
                await runs.RefreshAllAsync(CancellationToken.None);
            };
            _connection.Closed += _ => dispatcher.DispatchAsync(new HubStatusChanged(HubStatus.Disconnected)).AsTask();

            try
            {
                await _connection.StartAsync(ct);
                await dispatcher.DispatchAsync(new HubStatusChanged(HubStatus.Connected));
            }
            catch (Exception exception) when (exception is HttpRequestException or WebSocketException or InvalidOperationException)
            {
                await dispatcher.DispatchAsync(new HubStatusChanged(HubStatus.Disconnected));
            }
        }
        finally
        {
            _gate.Release();
        }
    }

    public async ValueTask DisposeAsync()
    {
        if (_connection is not null)
        {
            await _connection.DisposeAsync();
        }

        _gate.Dispose();
    }

    private HubConnection Build() => new HubConnectionBuilder()
        .WithUrl(new Uri(api.Value, Path), options =>
        {
            options.Transports = HttpTransportType.WebSockets;
            options.SkipNegotiation = true;
            options.AccessTokenProvider = ReadTokenAsync;
        })
        .WithAutomaticReconnect()
        .AddJsonProtocol(o => o.PayloadSerializerOptions.TypeInfoResolverChain.Insert(0, WorkflowRunsJsonContext.Default))
        .Build();

    private async Task<string?> ReadTokenAsync()
    {
        if (services.GetService<IAccessTokenProvider>() is not { } provider)
        {
            return null;
        }

        var result = await provider.RequestAccessToken();
        return result.TryGetToken(out var token) ? token.Value : null;
    }

    private async Task OnChangedAsync(WorkflowRunChanged change)
    {
        await runs.OnRunChangedAsync(change, CancellationToken.None);
        await tasks.OnRunChangedAsync(change, CancellationToken.None);
    }
}
```

```csharp
/// <summary>Four runs through the real store, one per state the console shows, plus the records the gate reads.</summary>
public sealed class RunSeeds(IWorkflowStore store, IServiceScopeFactory scopes)
{
    public Guid Running { get; private set; }
    public Guid AwaitingApproval { get; private set; }
    public Guid Succeeded { get; private set; }
    public Guid Failed { get; private set; }
    public IWorkflowStore Store => store;

    public async Task SeedAsync(CancellationToken ct)
    {
        Failed = await StartAsync("e2e-failed", ct);
        await store.FailAsync(Failed, "The publish step failed.", ct);

        Succeeded = await StartAsync("e2e-succeeded", ct);
        await store.CompleteNodeAsync(Succeeded, 1, new WorkflowTransition("done", WorkflowStatus.Succeeded, null, WorkflowEventKind.Completed), Ok, ct);

        AwaitingApproval = await StartAsync("e2e-gate", ct);
        await store.CompleteNodeAsync(AwaitingApproval, 1, new WorkflowTransition("review", WorkflowStatus.Running, null, WorkflowEventKind.Completed), Ok, ct);
        await store.CompleteNodeAsync(AwaitingApproval, 2, new WorkflowTransition("gate", WorkflowStatus.Awaiting, "human_approval", WorkflowEventKind.Awaiting), Ok, ct);
        await AppendReviewEvidenceAsync(AwaitingApproval, seq: 2, ct);

        Running = await StartAsync("e2e-running", ct);
    }
}
```
